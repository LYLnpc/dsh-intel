六、立即提升接单竞争力的组合

三个"装齐即战力"的套装，对应三种最典型的活儿。

  • 解决：手书接单最耗时的三段手工劳动（分层、画拍、改规格）全部免费自动化；补帧环节直接省掉 Twixtor/Flow 的付费预算。
  • 数据支撑：rife-ncnn-vulkan 1,130★ + 喵哉脚本 5,372 收藏证明"免费补帧"是中文二创圈已验证的真实需求。

组合 B：二创剪辑套装 ——「素材修复 → 投稿免二压」

TheAnimeScripter（或喵哉脚本）+ Real-ESRGAN + 小丸工具箱

  • 流程：素材超分/补帧/修复（AE 外或 AE 内二选一）→ 剪辑 → 小丸按 B站二压阈值压制收官。

七、避坑：看似热门，实际不需要或有风险

以下均直接引自两份报告的核实结论。

  1. 第三方"免费下载"站（freevideoeffect.com 一类）：全球报告明确警告——多为盗版/捆绑，社区确认有恶意软件风险。本清单全部条目只走官网/GitHub/作者原始渠道，看到"XX 插件合集免费打包下载"直接关掉。
  2. BeatEdit 没有免费版：中文报告核实——aescripts 上它是付费插件，B站教程视频只是演示工作流。手书打点走第一节「节拍打点工作流」的免费路径（Audition 标记 → AE），不必为此付费。
  3. KeTools 疑似不存在：中文报告多轮搜索（WebSearch × 2 + GitHub API）无法核实，疑似不存在、已改名或仅极小圈子流传。中文工具箱需求用已核实的替代：BHY 家族 / LoYoi AE6 / Z-Tool V1。
  4. B站营销号「插件合集一键安装包」：中文报告判定多为捆绑/诱导关注，非作者官方发布。免费脚本一律从作者 B站视频简介或 GitHub 原仓库领取。
  5. 网盘链接时效：喵哉脚本、Comp Setting Tool、小丸工具箱等走城通/百度/阿里云盘分发，时效无保证——中文报告要求"使用当天验证"，且其 GitHub 条目在核实当日全部可达。选型原则（中文报告结论 4）：优先 GitHub，网盘作备选。
  6. Twixtor 批量脚本 ≠ 免费 Twixtor：yanyiju 脚本只免费化"搭建变速合成结构"的工作流，Twixtor 本体仍是付费插件；没买本体的话，补帧/变速需求用 rife-ncnn-vulkan 或 TheAnimeScripter 替代。
  7. 大而全的中文工具箱性价比偏低：中文报告实测数据显示，"解决单一痛点"型工具收藏比显著更高（喵哉 5,372 收藏、CompChanger 926 收藏），而大而全工具箱普遍只有 2k-4k 播放量级（LoYoi AE6 4,038、工具箱大师 2,591、一只橘猫豆 3,489）。别被"一个面板解决一切"吸引，按痛点单点选装。
  8. Real-ESRGAN 第三方中文 GUI 整合包：中文报告提示网传整合包（如 updaterc 等）需注意来源甄别，最稳妥是直接用 GitHub 官方仓库或其明确列出的衍生生态。
  9. aescripts 的 NYOP 条目：EaseCopy、True Comp Duplicator、QCA3 等结账可填 $0，但必须注册 aescripts 账号；AEJuice 同理需注册。这不是坑，是门槛——提前知道免得以为"要付费"而错过。
