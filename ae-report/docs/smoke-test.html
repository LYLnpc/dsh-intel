# 复刻库实机冒烟测试清单（第一批 8 件）

- 适用：After Effects（建议 2018/15.x 以上；hose 的 createPath 表达式需 15.0+）
- 背景：全部 clone 未经 AE 实机验证；交叉评审后 flow/easecopy/tcd 有修复（枚举、removeKey、settings、按钮事件），本清单把修复点列为**重点回归**。
- 标注：🔴 = 重点回归（本次修复直接相关）；✅ = 通过判据。

## 0. 通用准备（约 10 分钟，一次完成）

1. 备用测试工程：新建 comp（1920×1080、25fps、10s）。
   - 纯色层 `SOLID1`：opacity 打 3 个关键帧（0→50→100，间隔 1s）；
   - 文本层 `TXT1`（随便一行字）；形状层 `SHAPE1`（矩形）；
   - 形状层加 Slider Control 效果并打关键帧。
2. 菜单 `Edit > Preferences > Scripting & Expressions`：允许脚本运行。
3. 表达式引擎先保持默认（JavaScript/legacy 都可），同组内不改。
4. 每步操作后：先看状态/弹窗文案，再 Ctrl+Z 验证整体可撤销，最后 Ctrl+Shift+Z 重做回到测试态。
5. 记录方式：每插件在"结果"栏记 通过 / 失败(现象截图或文案)。
