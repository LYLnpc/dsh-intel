一、PropertyValueType 枚举全表 [官方核实]

官方指南逐字原文（大小写敏感，grep 实证：OneD×3、TwoD_SPATIAL×13、ONE_D×0）：

枚举成员（唯一正确拼法）含义（指南原文摘译）value 形状
OneD浮点标量number（指南示例：opacity "has propertyValueType of OneD, and is stored as a float"）
TwoD二维数量值[x, y]（指南示例：Scale "might be [5.1, ...]"）
TwoD_SPATIAL二维空间值[x, y]（Anchor Point 等）
ThreeD三维数量值[x, y, z]（Scale 3D）
ThreeD_SPATIAL三维空间值[x, y, z]（3D Anchor Point）
COLOR颜色[r, g, b, (a)]，范围 [0.0..1.0]
MARKER层/合成标记MarkerValue 对象
SHAPE蒙版/形状路径Shape 对象
TEXT_DOCUMENT文本（Source Text）TextDocument 对象
CUSTOM_VALUE自定义数据自定义（指南示例：Levels 效果的 Histogram）
NO_VALUE无值—

易错拼法黑名单（评审实测踩坑）

错误拼法错在哪里
PropertyValueType.ONE_D / TWO_D / THREE_D全大写不存在。正确是混合大小写 OneD/TwoD/ThreeD。 ExtendScript 里访问不存在的枚举成员得到 undefined，比较恒为 false（不报错，静默失效）——最危险的一类错误
PropertyValueType.ValueType_ONE_D 等无此类成员（flow-clone 初版踩坑）
PropertyValueType.Text_Document / TextDocument正确为全大写 TEXT_DOCUMENT；COLOR/MARKER/SHAPE/NO_VALUE/CUSTOM_VALUE 同为全大写
字符串回退大小写String(prop.propertyValueType) 得到如 "TwoD_SPATIAL"，做子串判断时大小写敏感：indexOf("TWO_D_SPATIAL") 失败、indexOf("TwoD") 成功

比对示范（官方指南原文风格）：

if (myProperty.propertyValueType === PropertyValueType.ThreeD_SPATIAL) { /* ... */ }

二、关键帧时间缓动双接口 [官方核实]

读接口（每维一组 KeyframeEase）

// 签名 [官方核实]
prop.keyInTemporalEase(keyIndex);   // -> Array of KeyframeEase（读入方向）
prop.keyOutTemporalEase(keyIndex);  // -> Array of KeyframeEase（读出方向）
  • 返回数组长度 = 属性维度：TwoD/ThreeD → 2/3 个元素；其余所有类型（含 OneD 与 COLOR）→ 1 个元素（指南原文 "For any other value type, the array contains 1 object"）。
  • keyIndex 范围 [1..numKeys]。

写接口

// 签名 [官方核实]
prop.setTemporalEaseAtKey(keyIndex, inTemporalEase[, outTemporalEase]);
  • inTemporalEase/outTemporalEase：每维一个 KeyframeEase 对象的数组（TwoD→2 个，ThreeD→3 个，其他→1 个）。
  • outTemporalEase 省略时，出方向被设为与 inTemporalEase 相同——只改一侧时必须先读回另一侧：
// 单侧覆盖的安全写法（easecopy-clone 已按此实现）
var curOut = null;
try { curOut = prop.keyOutTemporalEase(ki); } catch (e) { curOut = null; }
prop.setTemporalEaseAtKey(ki, inEaseArr, (curOut !== null ? curOut : inEaseArr));

KeyframeEase 构造 [官方核实]

var ease = new KeyframeEase(speed, influence);
  • influence：浮点，范围 [0.1..100.0]（百分比）；speed：浮点（单位随关键帧类型不同，见 AE"关键帧速度"对话框）。
  • 官方示例（1D 与多维）：
// OneD 属性（如 Rotation）
myProp.setTemporalEaseAtKey(2, [easeIn], [easeOut]);
// 多维属性（如 Scale）必须每维一个元素
myScale.setTemporalEaseAtKey(2, [easeIn, easeIn, easeIn], [easeOut, easeOut, easeOut]);

缓动周边方法（指南收录）

[官方核实]：keyInInterpolationType(k) / keyOutInterpolationType(k) / setInterpolationTypeAtKey(k, inType, outType)、keyTime(k)、keyValue(k)、keySpatialContinuous(k)、keyRoving(k) / setRovingAtKey(k, bool)、keySpatialAutoBezier(k)、setTemporalAutoBezierAtKey(k, bool) / keyTemporalContinuous(k)、keyInSpatialTangent(k) / keyOutSpatialTangent(k) / setSpatialTangentsAtKey(k, inTan, outTan)、setValueAtKey(k, newvalue[, time])。 KeyframeInterpolationType.LINEAR / BEZIER / HOLD 三成员。

关键帧删除 —— 勿用 deleteKey [官方核实]

  • 官方指南唯一收录的删除方法：prop.removeKey(keyIndex)（grep 实证：removeKey×2、deleteKey×0）。
  • deleteKey() 不存在（flow-clone 初版踩坑，评审后已改 removeKey）。

指南未收录（社区通行，须 try/catch + 实机验证）

  • prop.isInterpolationTypeOK(keyType[, keyIndex]) [指南未收录] — flow-clone 用于能力探测，已包 try/catch。
  • app.getCommandLineArguments() [指南未收录] — flow-clone CLI 模式使用，AE CC2014+ 社区通行。

三、集合接口正确遍历 [官方核实]

集合正确遍历说明
项目条目for (i = 1; i <= app.project.numItems; i++) app.project.item(i)1-based + numItems；不存在 project.items[i] 数组式访问
comp 图层for (i = 1; i <= comp.numLayers; i++) comp.layer(i)同上 1-based
效果/蒙版/属性组for (i = 1; i <= grp.numProperties; i++) grp.property(i)1-based
合成选中项comp.selectedLayers（数组，0-based length 遍历）顺序无文档保证，勿假设
属性选中项comp.selectedProperties（数组，0-based）混合含 Property、PropertyGroup、Layer
属性选中关键帧prop.selectedKeys（数组，元素为 1-based 关键帧索引）用 length 遍历；排序需自做（sort(function(a,b){return a-b;})，ES3 无默认数值比较）
项目面板选中项app.project.selection（数组，0-based）
按名/按索引取图层comp.layer("名字") / comp.layer(i)名字不存在时抛异常（包 try/catch 或先遍历比对 layer.name）

要点："集合类用 numXxx + item(i)/layer(i)（1-based）；'选中的'类用 .length + [i]（0-based）"——两套索引风格并存是最常见踩坑点。

四、Property 核心方法签名 [官方核实]

prop.value;                        // 当前值；关键帧属性返回当前时间值
prop.setValue(v);                  // 仅限无关键帧属性；有关键帧时抛异常（指南原文明确）
prop.valueAtTime(time, preExpression);  // time 秒；preExpression=true 时取表达式应用前的值
prop.setValueAtTime(time, v);      // 该时刻无键则新建
prop.setValuesAtTimes(times, values);   // 两数组长度必须相同（指南原文 "the arrays must be of the same length"）
prop.nearestKeyIndex(time);        // 返回最接近 time 的关键帧索引
prop.numKeys;                      // 关键帧数（无关键帧属性为 0；PropertyGroup 上访问为 undefined，可作类型嗅探）
prop.expression;                   // 读写字符串；无效表达式赋值会抛异常
prop.removeKey(keyIndex);          // 删除关键帧（勿用 deleteKey）
prop.addProperty(matchName);       // 效果/蒙版/形状组追加子对象
grp.canAddProperty(matchName);     // 返回 bool

五、Layer / CompItem / TextDocument 常用成员 [官方核实]

Layer（图层）

  • 读 [官方核实]：index、name、comment、label、source（AVLayer）、parent、inPoint/outPoint/startTime/stretch、enabled/solo/shy/locked/guideLayer、blendingMode、trackMatteType、motionBlur、audioEnabled、autoOrient、threeDLayer、nullLayer、adjustmentLayer、timeRemapEnabled、environmentLayer、selected、selectedProperties、quality。
  • 方法 [官方核实]：copyToComp(targetComp)、moveAfter(layer)、replaceSource(item, fixExpressions)。
  • 图层创建 [官方核实]：comp.layers.addShape() / addNull() / addText(docOrString) / addBoxText() / addText(text)（竖排另有 addVerticalText） / addSolid(color, name, w, h, pixelAspect, duration) / addCamera(name, centerPoint) / addLight(name, centerPoint)。

CompItem（合成）

  • [官方核实]：width/height/pixelAspect/frameRate/duration/frameDuration/displayStartTime、numLayers/layer(i)、bgColor、motionBlur、shutterAngle/shutterPhase、workAreaStart/workAreaDuration、resolutionFactor、label/comment、parentFolder、selectedLayers/selectedProperties、layer("name")（不存在即抛异常）。
  • app.project.activeItem 可读写（15 处指南收录）；写前确认 instanceof CompItem。

TextDocument（文本）

  • [官方核实]：text、font、fontSize、applyFill/applyStroke、fillColor/strokeColor/strokeWidth、tracking、leading/autoLeading、baselineShift、justification、fauxBold/fauxItalic、boxText。
  • [指南未收录]（tcd-clone 在 try/catch 中作版本兼容尝试）：boxSize、paragraphJustification、antiAliasDirection、restHorizontalJustification。注意不存在 baselineLocShift，正确名是 baselineShift。
  • 构造：new TextDocument(text) 之后逐字段赋值。

其他对象要点

  • app.settings [官方核实]：getSetting(section, key)（缺失时抛异常）、getHavingSaved(section, key)（返回布尔"是否已保存"，不是值！）、saveSetting(section, key, value)、haveSetting(section, key)、saveToDisk()。安全读取模式：
try {
    if (app.settings.getHavingSaved(sec, key)) { return app.settings.getSetting(sec, key); }
} catch (e) { /* 缺失或异常 */ }
return fallback;
  • Item.duplicate() [官方核实]（footage 复制）、item.parentFolder 可写、item.id（数字，建议 String(id) 做映射键）、footageMissing。
  • MarkerValue：属性 comment/duration/label/chapter/url/cuePointName [官方核实]；层标记 parade 组 matchName 为 ADBE Marker Parade。
  • undo：app.beginUndoGroup(name) / app.endUndoGroup() 必须成对（推荐 try/finally）。

六、编码规范（复刻项目强制）

  1. 枚举名与 API 名一律抄本表，不凭记忆。拿不准 → 先查本文档或 print_page 原文，再落码。
  2. ExtendScript 访问不存在的对象成员不报错、返回 undefined——拼错枚举/方法名是静默失效，node --check 与 ES3 扫描均无法发现，必须 API 对照 + AE 实机冒烟（见 docs/smoke-test.md）。
  3. 新 API 用法须带 try/catch；指南未收录 API 禁止裸用。
  4. 交付前自查三件套：node --check（剥离 BOM/#target）→ ES3 扫描 → 对照本表逐个核对本文件出现过的 PropertyValueType.*、key*(、set*AtKey(、app.settings.* 名称。

七、纠错记录（本速查表编写过程中发现并已当场修复）

  1. 评审纠错（重要）：review-1 中我把 flow/easecopy 的枚举"修正"为全大写 ONE_D/TWO_D/THREE_D——方向反了。官方指南 grep 实证成员为混合大小写 OneD/TwoD/ThreeD（ONE_D 0 命中）。flow/easecopy 已当场改回；easecopy 原作者写的 OneD/TwoD 系列本就是对的（当时判其"致命"有误，但同文件确实存在 keyTemporalEase/缺 onClick 两个真 bug，修复仍然成立）。
  2. flow-clone 新发现真 bug：采样预设（Overshoot/Spring/Bounce）用 prop.deleteKey() 删中间键——该方法官方指南 0 命中，正确方法为 Property.removeKey(keyIndex)。已修复。此 bug 使三个采样类预设首删即抛异常（被上层 catch 计入 errors），属功能性损坏。
  3. tcd-clone 新发现真 bug：app.settings.getHavingSaved() 返回布尔而非字符串，原代码把它当值用（后缀/复选框记忆会静默变 true/false）。已改为 getHavingSaved 判断 + getSetting 读值的两段式。
  4. isInterpolationTypeOK、getCommandLineArguments 确认为指南未收录的社区通行 API（现有代码已包 try/catch，保留并在本表登记）。
