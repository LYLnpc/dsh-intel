## 安装前置知识：三类插件的存放位置（先读这段）

AE 第三方扩展分三种形态，装错位置是新手最常见问题：

| 形态 | 典型文件 | 放哪里 | 生效方式 |
|---|---|---|---|
| **aex 原生插件** | .aex | `C:\Program Files\Adobe\Adobe After Effects <版本>\Support Files\Plug-ins\` 或通用目录 `C:\Program Files\Adobe\Common\Plug-ins\7.0\Media Core\` | **重启 AE**，效果菜单里出现 |
| **jsx 脚本/面板** | .jsx / .jsxbin | 可停靠面板：`...\Support Files\Scripts\ScriptUI Panels\`（Window 菜单出现）；普通脚本：`...\Support Files\Scripts\`（File > Scripts 菜单出现） | 重启 AE 或 File > Scripts > Run Script File 直接跑 |
| **CEP 扩展** | .zxp / 扩展文件夹 | 经 ZXP 安装器装到 `C:\Users\<用户>\AppData\Roaming\Adobe\CEP\extensions\` | 重启 AE，Window > Extensions 菜单出现 |

另：用到脚本读写/联网功能的，先勾选 `Edit > Preferences > Scripting & Expressions > Allow Scripts to Write Files and Access Network`。本文每个插件标注了形态。

## 1. Duik Ángela —— 角色绑定/IK 骨骼套件（全榜免费热度第一）

1. **定位与价值**：行业级 2D 角色绑定/IK/自动动画工具，完全免费开源。对手书作者是"让人物真的动起来"的核心（先绑 IK/骨骼再摆姿势，免逐帧重画）；也是 AutoSway 等摆动类收费脚本的社区公认免费平替（见文末附注一）。
2. **获取路径**：官网 https://rxlaboratory.org/tools/duik/ （开源，可自愿捐赠，无需邮箱）；GitHub 仓库 https://github.com/RxLaboratory/Duik （已验证可达）。注：intel 核实记录显示 rainboxprod.coop 与 duik.rxlaboratory.com 在当时网络环境无法连通，**一律优先走 GitHub 仓库**。
3. **安装要点**：jsx 脚本套件（带安装器的面板脚本）。下载 Release 后按官方安装器走 ScriptUI Panels 方式装，重启 AE 从 Window 菜单打开；手动装则把 jsx 放 `Scripts\ScriptUI Panels\`。
4. **第一个动作**：新建合成 → 画一个两段式"大腿+小腿"形状层 → 用 Duik 的骨骼工具给关节打骨 → 拖末端骨骼看 IK 自动弯折。有手书人物的直接进 auto-rig 走一遍。
5. **社区热度**：B站播放量 1,042,181（B站榜第 1，31 个关联视频）；GitHub 408★（2026-11 实测，仍在更新）；Reddit r/AfterEffects 13 帖聚合中 4 帖 9 提及。

## 2. Saber —— 能量光剑/描边光效插件（Video Copilot）

1. **定位与价值**：100% 免费的能量光剑/激光/霓虹描边特效插件。手书打斗光效、MV 音 bomb 段落、Logo 点火，套上再改颜色即可，不用手搓光效。
2. **获取路径**：官方发布博文 https://www.videocopilot.net/blog/2016/03/new-plug-in-saber-now-available-100-free （免邮箱直下）。注：intel 核实 `videocopilot.net/products/saber/` 已 404，**有效入口就是上面这个博文页**。
3. **安装要点**：aex 原生插件 → 放 `Plug-ins\` 或 `Common\Plug-ins\7.0\Media Core\`，重启 AE，在 效果 > Video Copilot > Saber 找到。
4. **第一个动作**：对文字层（或遮罩层）加 Saber → Core Type 选 Text/Layer Paths → 拖 Glow Intensity 和 Distortion 看能量描边实时变化。
5. **社区热度**：B站播放量 708,884（B站榜第 2）；Magic Mark 2025 免费榜第 9；YouTube 盘点常客；VC 官方免费主打。

## 3. Motion Tools 2 —— 锚点/缓动/对齐效率面板

1. **定位与价值**：锚点、缓动、对齐、变换多功能效率面板。MG 动画日常工作流加速器，对 PV/剪辑作者是"少进菜单"的省时工具。
2. **获取路径**：B站榜口径为"免费（作者发布）"，经 B站分发——**榜单未提供站外直链，从作者 B站视频简介领取**（B站榜第 8 名关联视频可顺藤摸瓜）。
3. **安装要点**：jsx 面板 → `Scripts\ScriptUI Panels\`，重启 AE 从 Window 菜单停靠。
4. **第一个动作**：选中一个图层 → 用面板的锚点工具把锚点快速放到图层中心/角点 → 再给两个关键帧套一次缓动，感受一遍工作流。
5. **社区热度**：B站播放量 230,717（B站榜第 8，11 个关联视频；代表视频《免费的你要不要？中文汉化 Motion Tools 2》13.8 万播放）。

## 4. FX Console —— 效果/预设秒搜控制台（Video Copilot）

1. **定位与价值**：一键搜索/套用效果与预设的效果控制台。工作流类第一神器：效果全部按名字秒搜秒套，替代翻菜单，对每天要翻几十次效果菜单的 PV/剪辑作者是刚需。
2. **获取路径**：https://www.videocopilot.net 站内 Downloads（FX Console v1.0.7），免邮箱直下。
3. **安装要点**：aex + 面板混合形态，装完重启 AE，默认快捷键 Ctrl+Space（可在键盘编辑器里改）。
4. **第一个动作**：装完**先绑定一个快捷键** → 选中图层按快捷键 → 输入中文/英文名（如"Glow"）回车，效果直接挂上——第一次命中就有获得感。
5. **社区热度**：Reddit r/AfterEffects 多帖公认"第一必装"（pusdsi、1flmaip 等帖）；Magic Mark 2025 榜收录；B站播放量 197,528（B站榜第 9）。

## 5. True Comp Duplicator —— 预合成树完整复制脚本

1. **定位与价值**：完整复制选中合成及其全部子合成层级树（AE 自带只是浅复制）。接单作者的客户改稿刚需：换个颜色/角色再出一版，用它复制整条链再改，不手动另存。
2. **获取路径**：https://aescripts.com/true-comp-duplicator/ ，**NYOP（Name Your Own Price，建议价 $24.99，结账可填 $0），需注册 aescripts 账号**。

4. **第一个动作**：随手做个"主合成 + 2 层嵌套子合成"小工程 → 跑一次 TCD → 看到 3 个合成被完整复制且引用关系保留，就理解了它和 AE 自带复制的区别。
5. **社区热度**：Reddit 13 帖聚合中 **7 帖推荐、23 次提及，脚本类第一**；B站播放量 136,673（B站榜第 11）。

## 15. Adobe Media Encoder —— AfterCodecs 的免费替代（随 AE 附带）

1. **定位与价值**：AE/PR 官方渲染输出编解码扩展 AfterCodecs（~$105，paid-list #45 标 C 类不可复刻）的免费替代就是随 AE 安装的 AME：ProRes/H.264/H.265 全支持，后台队列渲染不锁 AE。B站榜第 5（AfterCodecs 播放量 672,174）说明"渲染输出"是最大刚需之一——这个需求可以零成本满足。
2. **获取路径**：无需获取——随 After Effects 安装自带（Creative Cloud 桌面端可确认已装）。
3. **安装要点**：AE 里 `File > Export > Add to Adobe Media Encoder Queue`（或渲染队列输出模块"AME"按钮）；首次打开 AME 确认导出预设里 ProRes/H.265 可用。
4. **第一个动作**：把当前合成推到 AME 队列 → 选 H.264 匹配源高比特率 → 渲染 → 对照 AE 内直接输出，感受"不锁 AE"的工作流差异。
5. **社区热度**：paid-list 结论原文："替代：Adobe Media Encoder（免费随装）"；B站 AfterCodecs 相关视频 672,174 播放（B站榜第 5），免费侧需求热度最高的一类。
