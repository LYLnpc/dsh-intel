replicas-boundary

9 件复刻的真实边界

先说结论：9 件都能跑、都覆盖了各自商品页宣传的主路径，但没有任何一件等于原版。差异集中在三类：依赖外部资产的做不到（字形库、伪效果）、需要原生渲染/另一宿主的功能做不到（aex 内核、Ai 端扩展、PR 端）、体验层的都没做（实时预览、indicators、库管理）。
#复刻件对应原商品主路径与原版最大差距
1trim-comp-cloneTrim Comp to Contents合成时长贴合内容不认表达式/像素层面的"内容"
2project-item-labels-cloneProject Item Labels按类型批量上标签色读不到颜色值，只能写索引
3move-anchor-point-cloneMove Anchor Point 4锚点吸附 9 位 + 补偿位置无"视觉重心"，只在播放头取样
4scribe-cloneScribe单线字逐笔写出字形是公版 Hershey，不含原版 6 套字
5easify4-cloneEasify 4缓动预设 + 跨属性同步无 Speed Graph 画布、无 PR 端
6overlord-cloneOverlordSVG → AE 形状层单向，无 Ai 端实时联动
7limber2-cloneLimber 2双骨 IK 肢体 + 样式库只有 Path 型 2-bone，无 Puppet/Precomp/3-bone
8keyframe-parent-cloneKeyframe Parent关键帧组整体变换重建式写入，roving/选中态丢失
9retend-cloneRetend整棵 precomp 树重定时行为模型自行设计，表达式内时间不缩放

1. trim-comp-clone（Trim Comp to Contents）

已覆盖

  • 内容范围 = 全层 inPoint/outPoint 并集；预合成层 outPoint 被过短合成夹掉时，用 startTime + source.duration × stretch 反推真实尾端。
  • 执行序：先平移图层 → 需要变长就先加长 → 最后才缩短（加长永不丢键，缩短才是 trim 的语义）。
  • 帧对齐（frameDuration 四舍五入）、工作区同步为 0 ~ duration。
  • 选项：忽略参考层 / 忽略关闭层 / 跟随嵌套预合成 / 内容归零 / 仅选中层 / 尾部留白帧数。

明确没做

  • 不认表达式造成的视觉延伸（2 秒层 + loopOut() 画面能一直延伸，脚本只看到 2 秒）。
  • 预合成只递归一层，不跟着进它内部的预合成。
  • "内容"口径是时间跨度，不是"画面上有非透明像素"——10 秒全黑素材仍算 10 秒。
  • 不裁图层自身的 in/out，只改合成时长与工作区。

参数级取舍

  • 缩短后 AE 不可逆（除撤销）：脚本没有"预览差异"步骤，靠面板 Refresh 先看目标时长。
  • 平移模式会跳过锁定层（失败不报是哪一层）。

2. project-item-labels-clone（Project Item Labels）

已覆盖

  • 9 类规则（丢失 / 占位 / 纯色 / 合成 / 文件夹 / 图片 / 视频 / 音频 / 其他）× 标签索引 1–16。
  • 判定优先级把 footageMissing 放最前——否则丢失素材会因为还留着扩展名被错标成图片。
  • 范围：整项目递归 / 仅选中项；可"跳过已符合项"。

明确没做

  • 读不到实际 RGB，只能写索引（索引对应什么颜色由用户 AE 首选项决定）。
  • 不改图层标签（layer.label 是另一套面板）。
  • 不做文件名关键字智能（_final、_v2 之类）。
  • 无预设保存（关面板即丢）、无预览。

参数级取舍

  • 下拉里的颜色名按 AE 出厂预设写，用户改过首选项后名称会不准，实际以索引为准。
  • 不提供索引 0（部分版本上会报错/恢复默认）。

3. move-anchor-point-clone（Move Anchor Point jsx 版）

已覆盖

  • 9 个位置（四角/四边中点/中心）+ 自定义 0–1 百分比。
  • 用「设新锚点 → toComp 差分反算 position」补偿，缩放/旋转/父级链/3D 全交给 AE 自己的矩阵，不自己推旋转顺序。
  • 分离维度的 position/anchor 会检测出来跳过并报明原因。

明确没做

  • 没有"视觉重心"模式：对齐的是 sourceRectAtTime 的包围盒，不看像素透明度。
  • 只在播放头取样一次；内容随动画变化（打字机、形状变形）时锚点不跟着走。
  • 摄像机/灯光层没有内容框，直接拒绝；3D 图层的锚点 Z 不动。
  • 不支持"吸附到蒙版/形状单个顶点"。

参数级取舍

  • 有 keyframe 的层会 setValueAtTime 在当前时间写新键（setValue 会抛异常），状态栏会提示。
  • Auto-Orient 层的朝向由运动决定，改 position 理论上存在极小残余偏差。

4. scribe-clone（Scribe）

已覆盖

  • 5 款公有领域 Hershey 单线字内联（21KB 紧凑串、9743 个点），零外部文件依赖。
  • 文本 → 逐字符一个形状层，层内 <多 path → Trim → Stroke>（顺序必须这样，Trim 排在 Stroke 之后肉眼完全看不出书写）。
  • Trim End 两键 0→100 + BEZIER/KeyframeEase(0, 66.67)，逐字按层序 × delay 错开；write off 反向 100→0；on-then-off 再补 Trim Start 0→100。
  • 参数：5 字型 / 字号 / 字距% / 行距% / 描边宽 / hex 颜色 / 每字延迟帧 / 单字时长帧。
  • 层序 = 书写顺序，拖动层即可重排。

明确没做

  • 中日韩全不支持（Hershey 只有拉丁；CJK 走"跳过 + 列出被跳过字符"，全不可写时直接报错，绝不静默出空层）。
  • 生成后不能改字（形状层，只能重生成，原层描边/关键帧不会迁移）。
  • 没有 Effect 滑杆实时拖进度（用关键帧驱动，理由见取舍）。
  • 没有 kerning 微调、没有笔画粗细随速度变化、没有闭合字形的接缝处理。

参数级取舍

  • 字形是 Hershey 工程单线字，不是原版那 6 套手写美术字——行为等价、字形不同，观感明显更"硬"。原版字型是版权资产，不能碰。
  • 长文本限 60 字符（每字符一层 + 每笔一条路径，再多会堆层）。
  • 垂直对齐：Hershey 设计数据的基线在 y=22（字冠在 y=1），字号缩放用字冠高 21、基线归零用 22 分开算——评审轮修过一次（原先两者混用 21，会让整行字上移约一个字号的 4.8%）。
  • 用关键帧而非滑杆：滑杆版要给每个 group 写引用滑杆的表达式，长文本上表达式开销随组数线性涨。

5. easify4-clone（Easify 4 · AE 端）

已覆盖

  • 9 个预设：AE 默认 33/33、Ease In Out、Ease Out、Ease In、Maximum 100、Linear，加 Back / Bounce / Elastic（采样烘焙）。
  • 多属性批量：遍历 comp.selectedProperties，逐属性逐段 try/catch，失败计数不中断。
  • 跨属性归一化同步：记源的 u=(t−t₀)/(t₁−t₀) 与 in/out influence，套到目标自己的时间跨度；每个 u 先用 valueAtTime 取目标自身值再建键——保住目标数值曲线，只搬缓动形状。
  • 循环 pingpong（每轮镜像时间，转折点无跳变）/ repeat；整键偏移帧数；首末固定中间等距。

明确没做

  • Premiere Pro 端不做（PR 无公开的关键帧缓动脚本 API）。
  • 没有可拖拽的 Speed Graph 画布（ScriptUI 命中测试成本过高）。
  • 多点曲线是采样近似（逐帧烘焙后转 LINEAR），不是真多点手柄。
  • 复合曲线叠加（官方语义无公开定义）、路径缓动、Wiggle/Impact、预设库保存。

参数级取舍

  • 贝塞尔预设只改 influence，speed 按该段实际斜率逐维算（(v₂−v₁)/(t₂−t₁)）；另给 Flat handles 开关退回 speed=0 的 AE 经典行为。
  • 烘焙遇到段内已有键直接跳过该段（返回 −1），不强行覆盖；键数会涨且之后不能再调曲线。
  • 偏移/均分走"读全键 → removeKey 全部删掉 → 按新时间重建"，重建后缓动回到默认值。
  • 同步后 speed 归零（形状优先、幅度不变），目标段很长时观感偏"顿"。

6. overlord-clone（Overlord · 单向 SVG → AE）

已覆盖

  • 自写 SVG 解析器（ExtendScript 没有 DOMParser）：剥注释/<?xml?>/<!DOCTYPE> → 标签正则 + 栈建树 → 属性正则，保留 inkscape:label。
  • <path d> 支持 M L H V C S Q T Z 绝对+相对；Q/T 按 2/3 规则转三次，S/T 用反射控制点；切线存成相对顶点的偏移。
  • transform：translate / scale / rotate（含中心）/ matrix 矩阵累乘。
  • <rect> <circle> <ellipse> → 参数化形状（Rect/Ellipse 的 Position/Size/Roundness），不是死点。
  • <g> → ADBE Vector Group，名字取 inkscape:label → id → Group；fill/stroke 属性继承。
  • 缩放映射（Fit to comp 等比 / 原尺寸），layer.comment 记来源，Update 按 comment 找回原文件重推、不新建层、可打关键帧。

明确没做

  • AE → Ai 回推（需要 Illustrator 端 CEP 扩展）、Ai 实时联动（无剪贴板 API，要存 SVG 或粘贴代码）。
  • 弧线命令 A 降级成直线段（并告警）。
  • 渐变降级为无填充（并告警）；<text>（要先 outline）、<image>、<use> 跳过并告警。
  • clip-path / mask / filter / <pattern> 静默忽略；不做色彩管理。
  • Update 只更新每层的第一条路径，不按选中的具体 group/path 定位；也不新建样式（连颜色都不改）；且只支持 bezier 路径——若第一个形状是参数化矩形/椭圆（没有 ADBE Vector Shape 属性），直接报错要求先在 AE 里 Convert to Bezier Path，不会抛出原始异常。

参数级取舍

  • 每个图形元素包一层自己的子 Group（样式隔离）——否则一个 <g> 里两条不同颜色的 path 会互相叠色、组上堆重复 Fill/Stroke。
  • 缩放只乘一次：viewM 已含 viewBox 缩放，几何与线宽一律取矩阵缩放因子，不再乘全局 scale。
  • <g transform> 在生成时烘进坐标，AE 里那个 Group 的变换是单位矩阵（想整体移动要手动加变换）。
  • 带旋转的 <rect> 降级为 4 点路径（参数化形状表达不了旋转）。

7. limber2-clone（Limber 2 · 双骨 IK）

已覆盖

  • 一键生成 6 个控制 null + 1 个形状层；双骨 IK 用余弦定理，含可达域钳制（拉到 L1+L2、折到 |L1−L2|）与零除/NaN 保护。
  • 轮廓：中心线采样 → 法向偏移闭合环（含两端圆帽）→ Catmull-Rom 切线，全部在表达式里逐帧算（jsx 只建层、挂 Slider、写表达式串）。
  • Style 1–4（圆润/尖锐/弹性/直管）+ Smooth 微调；squash & stretch 按"当前根末距离/骨总长"与 rest 比值做体积感缩放。
  • Body + Highlight 两组分层配色（提亮 45%）；Hi % / Hi Off 控制高光带宽与偏向。
  • 手/脚：绑定选中层到 TipBone（位置补偿回原位，可选是否跟随旋转）；一键生成圆手/脚。
  • 打帧：当前姿势打键 / 生成 4 姿势椭圆循环（带贝塞尔缓动）；7 个内置样式预设 + 存自定义到 AE 首选项。
  • Upper / Lower / TipBone 三个骨轴 null 可父化自绘 artwork；多肢体并存（LC1…LCn 编号）。

明确没做

  • Puppet 型（木偶钉位置无公开脚本 API）、Precomp 型、Taper/Circles/Shape 型（只做 Path 型）。
  • 3-bone（双关节 + 两个 FreeK + 5 个 Weight）。
  • Indicators / Limb Library / Auto-flop / Matching / 整条肢体复制粘贴。
  • 伪效果（jsx 建不出伪效果）→ 参数改成多个 ADBE Slider Control / Checkbox Control。
  • 真正的弹簧时间积分：弹性弯是"压缩程度驱动的静态外凸 + 正弦鼓起"，没有历史速度。

参数级取舍

  • 骨段固定为 2（双骨 IK 的定义），没有"每条骨再细分数段"。
  • 参数全挂在 Joint 层上（表达式读自己的效果）。
  • 形状层变换恒等（position[0,0]/anchor[0,0]）→ 整层不能随便位移/旋转，要动请拖 Root。
  • 重命名 LC* 图层会断开表达式引用（表达式按层名引用）。
  • 3D 图层只取 XY 平面。

8. keyframe-parent-clone（Keyframe Parent）

按该件 README「诚实限制」如实转录。

已覆盖

  • 关键帧组当对象整体变换：父化/平移/拉伸（Capture 快照 → 拖拽 → 写回）。
  • 支持数值与颜色属性：OneD / TwoD / ThreeD / TwoD_SPATIAL / ThreeD_SPATIAL / COLOR。
  • 构建校验会先挡掉绝大多数可预见失败；整步一个撤销组。

明确没做

  • roving（漫游）标记不恢复；空间切线按原值回填但幅度不随缩放换算；关键帧标签与"选中状态"不保留（重建后键不再处于选中态）。
  • SHAPE（蒙版路径）/ TEXT_DOCUMENT / MARKER / CUSTOM_VALUE 直接跳过并计数。
  • 不做静默避让：新时间与组外键冲突（< 0.0005s）→ 该属性整体放弃并报错，不偷偷 +1 tick。
  • 不改表达式（有表达式的属性写入会被表达式覆盖，看起来"没反应"）。

参数级取舍

  • 跨属性缩放没有统一物理意义：值缩放逐分量作用在各自原生单位上（Scale 是 %、Position 是 px、Opacity 是 %），父键只对它所属属性做值支点。
  • 拖动滑杆期间不写 AE，松手才写；"实时预览"不是逐帧拖动预览。
  • 预览也是真写入：Preview/松手都会产生撤销步。
  • 刻意未用 comp.time（不在白名单）→"对齐播放头"改为手填目标秒数。

9. retend-clone（Retend）

按该件 README 的限制章如实转录。

已覆盖

  • 整棵嵌套 precomp 树的 Extend（延长）/ Retime（重定时）。
  • 关键帧时间缩放时，值与时间同步缩放（remap 的值本身是源时间，必须同乘比例）——这是这类工具最深的坑。
  • 可选的"素材层同步变速"（写入时间重映射）；层标记时间缩放。
  • 对象同一性防二次缩放；先收集后删除再重建的管线；逐层 try/catch 警告汇总。

明确没做

  • 表达式内写死的时间/帧号不随比例缩放（表达式原样保留）。
  • 音频不变速（时间重映射不作用于音频；含音频层时给警告）。
  • Extend 只延长"出点 ≈ 旧 comp 时长（容差半帧）或更靠后"的层，中途结束的层不动；不截断已 ≥ 目标时长的 comp。
  • Retime 不缩放图层 startTime / stretch（素材层默认保持 1:1 推进）。
  • 跨树共享子 comp 先到先得（多选根时只按先遇到的参数处理一次）。

参数级取舍

  • 行为模型为自行设计：原品无公开技术细节，Extend/Retime 的边界语义与原品的取舍可能不同。
  • 关键帧缩放 = 删除重建：落在同一帧的键合并（可能丢键）；极端情况下属性可能半删状态——整步一个撤销组，Ctrl+Z 可整体回滚。
  • ADBE Time Remapping 定位失败时降级为普通属性（只缩放键时间、不缩放键值）并警告。

汇总：9 件的共同短板

  1. 全部未在 AE 实机跑过（本机无 AE）：语法/ES3/API 名/数学都做了离线验证（node --check、ES3 扫描、IK 与 SVG 解析器的纯函数测试），但"在 AE 里第一次点下去是什么效果"仍需实测。
  2. 体验层一律从简：没有一件做了原版的实时预览、指示器、库管理器、拖拽面板。
  3. 依赖外部资产的功能一律用公版替换：Scribe 的字形（Hershey）、Limber 的外观素材（参数化预设而非美术素材库）。
  4. 跨宿主的一律砍掉：Overlord 的 Ai 端、Easify 的 PR 端。
  5. 原生内核的一件没碰：9 件全是 jsx，没有任何 aex 逆向或渲染内核复刻——这也是 A 类筛选的意义。
