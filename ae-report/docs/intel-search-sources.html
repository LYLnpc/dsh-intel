三路的正确用法（按实测）

  • B 站：要"使用量"就必须走 bili_search，它带 play/review/danmaku/pubdate；platform_search bilibili 只适合找线索，不能拿来做排序依据。中文插件口碑、汉化版是否存在、UP 主实测，都看这里。
  • YouTube：当前拿不到。恢复后建议优先用它核对英文评测的真实播放量（本群已有若干"社区口碑"判断缺英文播放数据支撑）。在恢复前，英文评测改用 web_search 找站点文章，不假装有视频数据。
  • X（推特）：鉴权缺失，拿不到搜索。按"拿不到就走间接索引"的口径：只在 web_search/exa 的搜索结果里出现 X 链接时引用，且标等级 C，不主动去抓 X 正文。需要真用 X 得先配 Grok/X Premium 鉴权，这不属于我这边能自行解决的。

三、坑与绕法（实测记录）

  1. aescripts 直连被盾：r.jina.ai 代理超时、allorigins 偶发可用（Trim Comp to Contents 的 meta description 就是这么拿到的）、codetabs 代理失败、Wayback 对这些商品页多数无快照。兜底顺序：商品摘要搜索 → 代理页 → allorigins → 放弃并标 B/C。
  2. Reddit 拒爬：固定走 exa 间接索引，别再试 old.reddit。
  3. sogou 出验证码；bing 会拆词给垃圾结果（查 "Trim Comp to Contents" 返回 "SSD 的 TRIM"），专有名词不要用 bing。
  4. tavily 有日额度上限（撞过 429 daily_cap_reached），别把主检索压在它身上。
  5. ddg / searxng 本轮多次超时，重试一次不成就换 exa。

四、给"使用量排序"的口径（不变）

AE 插件圈没有公开下载量。"使用量" = 四路合成：B站播放/收藏（bili_search 一手）+ GitHub star/推送（API 一手）+ 商品页评分与评论数（多为 B 级）+ 讨论热度（C 级）。缺任何一路都要在结论里写明缺哪路。
