一、缓动/动画控制类（A 类，复刻重点，描述最细）

1. Flow [A类] [已核实]

  • 官方页：https://aescripts.com/flow/
  • 价格：$35（Single User License；Floating 另购 FLS $99.99）
  • 格式：CEP/HTML 面板 + jsx（版本日志同时更新 JSX 与 CEP 许可框架，混合实现）
  • 作者：renderTom (Tom Clemenhagen) + Zack Lovatt
  • 兼容：AE 17.0/CC2020 起（1.5.1 后最低 17.5），到 2026
  • 核实状态：商品页全文抓取 ✅

核心功能（分点）：

  1. 曲线编辑器：一个归一化(normalized)的缓动曲线画布，替代 AE 内置速度/影响图形编辑器。拖动 2 个贝塞尔控制点定义 ease 曲线；Shift+拖拽吸附到网格格点；v1.5 起支持 responsive overshoot/undershoot（曲线可超出 0–1 值域，即过冲回弹）；可选反转曲线值显示方向。
  2. 预设库（Library）：把当前曲线 Save Preset 存入库；v1.5 支持多库（multi-library）切换、拖拽重排、库导入/导出分享；内置 25 条常用曲线；官方页提供社区预设包下载（Oddernod/Ryan Summers 包、Andrew Embury 包、Matthew Law 包、Workbench 包、Google Material Design 缓动曲线包等）。
  3. 应用方式二选一：
  • Keys：把曲线写入选中关键帧的 easeIn/easeOut（贝塞尔控制参数按时间跨度与值跨度归一化换算为 keyframeEase 的 influence/speed）；对未分离维度的 Position 会提示分离维度。
  • Expression：把曲线作为表达式写入属性（用 ease 近似 cubic-bezier），可记住"记住表达式应用行为"偏好。
  • 修饰键：Ctrl/Shift/Alt 组合实现反向(inverse easing)、镜像等（1.4.0b：SHIFT+CTRL 反转缓动）。
  1. Read Values / Edit Curve：读取现有关键帧缓动回编辑器；若关键帧已带 Flow 表达式，能识别出原始曲线并选中对应库项；"Last Curve"可视化与偏好。
  2. 集成：导出库到 KBar（一键把库曲线变成 KBar 按钮）；复制曲线为 CSS cubic-bezier() 格式；控件位置可配置（上/下）。
  • 复刻要点：
  • 数学核心 = cubic-bezier 参数 (x1,y1,x2,y2) ↔ AE 关键帧 easeIn/easeOut(influence, speed) 的双向换算。x 是时间比例，y 是值比例；AE ease 用 speed(p/s)+influence(%) 表示切线，需推导公式。
  • 库文件存 userData/磁盘 JSON（1.3 起写入磁盘可跨 AE 版本同步）。
  • UI 用 ScriptUI 画布或 CEP canvas 均可；表达式模式需要生成安全表达式字符串（注意 JS 引擎 16.0+ 兼容）。

2. EaseCopy [A类] [已核实]

  • 官方页：https://aescripts.com/easecopy/
  • 价格：$15（Name Your Own Price，个人可少付）
  • 格式：jsx（ScriptUI 面板 + 3 个独立快捷键脚本 + KBAR 包）
  • 作者：Mike Overbeck
  • 兼容：CS6 – AE 2026
  • 核实状态：商品页全文抓取 ✅

核心功能（分点）：

  1. Copy：复制选中关键帧的"缓动"到剪贴板（userData 持久化），不带数值。
  2. Paste Eases：把缓动粘贴到目标关键帧；智能缩放：自动按目标段值域/时长比例缩放 ease 数值；自动翻转：目标速度方向与来源相反时自动镜像缓动；跨属性类型通用（一切可插值属性）。
  3. Paste Values：只粘贴数值不覆盖缓动（属性类型必须匹配）。
  4. 数量规则：粘贴目标键数必须等于剪贴板键数或为其整数倍。
  5. Pass-through：优先匹配"穿过速度"（intermediary keyframes 的穿行速度），适合 ≥3 连续关键帧串，避免速度断点。
  6. 集成：KBAR 一按钮化；Command Frame 可搜索调用；独立 Copy / Paste Eases / Paste Values 脚本可绑 AE 键盘快捷键。
  • 复刻要点：KeyframeEase{influence, speed} 读写 + 按值域/时长缩放 + 方向翻转 + pass-through 匹配算法；UI 极小面板常驻。

3. Motion 2 (Mt. Mograph) [A类] [已核实-摘要]

  • 官方页：https://mtmograph.com/products/motion（aescripts 无 Motion 2 页面，404 已验证）
  • 价格：$65（2014-12-09 首发价）
  • 格式：jsx ScriptUI 面板
  • 作者：Mt. Mograph（Matt Jylkka）
  • 核心功能：
  1. Ease 滑块：面板中央三段滑块，选中关键帧一键写入 ease（ease-out / easy-ease / ease-in），本质是批量设置 keyframeEase（influence/速度预设）。
  2. Burst：一键生成放射状爆发图形（自动复制形状层、旋转分布、缩放+不透明度关键帧）。
  3. Anchor Point 工具：把锚点移到图层几何中心/指定点且保持画面位置不动（锚点移动补偿 position）。
  4. Direction：水平/垂直翻转动画方向（交换首尾关键帧值）。
  5. Clone/复制关键帧：按帧偏移复制关键帧序列。
  6. Rig：父子绑定辅助工具。
  7. 兼容 AE 2018/2019+（升级 AE 需重装面板）。
  • 复刻要点：全部是关键帧/图层属性操作，无渲染内核；Ease 滑块 = Flow 的简化版。

7. Joysticks 'n Sliders [A类] [已核实]

  • 官方页：https://aescripts.com/joysticks-n-sliders/
  • 价格：$39.95
  • 格式：jsx（ScriptUI 面板 + 表达式绑定生成器）
  • 作者：Mike Overbeck（同作者：EaseCopy、Limber、Parrot、Squirrel、WobbleBox）
  • 兼容：CC – AE 2026（1.7.5 曾短暂不兼容 CS6）
  • 核实状态：商品页全文抓取 ✅

核心功能（分点）：

  1. Joystick：摆好 5 个连续关键帧表示 origin / 右 / 左 / 上 / 下 极端姿势 → 选中这些图层 → 一键在合成窗口创建 Joystick 控制器 Null；控制器 2D 位置驱动四象限姿势双线性插值（表达式的 layer index 引用生成的姿势层）。典型用途：3D 角色面部（嘴型、眼球朝向）。
  2. EaseBias：控制 joystick 插值的偏置曲线（1.5 新增）。
  3. Switch Template：为"可替换部件"（不同角度嘴型包等）自动按 joystick 所在象限切换素材图层。
  4. Sliders：与 joystick 同一套姿势思路但姿势数量无上限：每个姿势对应一个滑杆，可任意混合（权重叠加），适合手、眼、嘴、整套身体姿势，也可用于纯 MG 抽象动画；支持正向/反向 posing（1.1 起反向为默认）。
  5. Path Shape Rigging（v1.6+）：把形状路径顶点绑定到控制器（joystick 或 slider），实时变形路径（依赖 CC2018 新 JS 表达式引擎，1.7 大幅提速）；Path Flipper 加速路径翻转 rigging。
  6. UI Sliders：在合成内创建可视化滑杆控件层。
  7. Move to Parent / Move to Child：把控制器挪入父 comp（跨 comp 驱动，支持分离维度与父级化的 Origin）或收回子 comp；rig 与 BodyMovin'（lottie）导出兼容。
  8. 试用限制（功能边界线索）：7 天、每个 Slider Null 限 4 个滑杆、禁用控制器挪父 comp。
  9. 与 puppet pins、Limber、BAO Bones、PuppetTools、DUIK、RubberHose 配合良好。
  • 复刻要点：核心是"姿势层选择 → 生成引用 layer(index) 的插值表达式骨架 + 控制器命名约定"；路径绑定需逐顶点 lerp 表达式；跨 comp 用 comp(name).layer() 引用。

七、给复刻组的结论与建议

  1. A 类（jsx 可复刻）清单（按"价值/难度"建议复刻顺序）：
  2. EaseCopy（小而准，价值高）
  3. Flow（核心=贝塞尔↔ease 换算，UI 可简化为 ScriptUI）
  4. AutoSway（表达式弹簧链）
  5. True Comp Duplicator（工程量大但纯逻辑）
  6. KeyTweak（小工具）
  7. Parrot / WobbleBox（表达式系统）
  8. Joysticks 'n Sliders（姿势插值骨架，中等偏大）
  9. RubberHose 3 / Limber 2（IK+形状轮廓表达式，大工程）
  10. 其余小工具（KeyMaster、Ease Stash、Again!、Add Sauce、Retend、Easy Bake、Trim Comp to Contents、Project Item Labels、Slice it Up 2、Roll it!、Scribe、MoveAnchorPoint、Rows and Columns）均为纯脚本逻辑，可作为任务池批量复刻。
  11. A 类共性：全部通过 AE Scripting API（app.project / layer.property / keyframeEase / 表达式字符串生成）实现，无 C++ 依赖；复刻不涉及渲染引擎。
  12. B 类用原生效果组合近似即可，不必复刻为独立插件。
  13. C 类不要投入复刻，直接走免费替代（Mocha AE、C4D Lite、Lumetri、AME、Keylight、Lens Flare+素材）。
  14. 价格时效：aescripts 长期打折，写报告时用"常规价"并注明 NYOP（Name Your Own Price）机制存在（EaseCopy/KeyTweak/True Comp Duplicator/Again!/WobbleBox/Trim Comp to Contents/Project Item Labels 均为 NYOP，个人用户可低于标价获得）。
  15. 本次未能完成：Rows and Columns、LongShadow 2、Datamosh 的价格/参数级核实；B 站/YouTube 演示视频简介源未及采集（时间受限）。MoveAnchorPoint 与 AutoFill 已在收尾轮补核。
