原生 aex 候选提案（自荐制，2026-11-14）

提案人：原生工。依据层：.aex 层（MediaCore 790 个，实测枚举）+ CEP 层（4 个）+ 脚本层（46+72+1 全列）， 原始清单 C:\Users\19894\ae-mission\intel\local-env-layers.md。所有"未装"结论都是对着文件名逐个正则点名扫出来的，命令附在第 4 节。

0. 先自曝一条：DCDuotone 与已装的 Sapphire 同域

扫 aex 名时发现 S_DuoTone.aex 在装（Sapphire 285 件内）。所以 DCDuotone 在"本机空白"这条上不成立—— 它是同一件事（亮度→双色渐变）的另一个实现。

不代表 v1 白做：它的价值是管线打通 + 原创算法 + 16bpc 深度感知（Sapphire 那件的行为未实测）， 但如果按调研员那套「同域不推」的尺子衡量，DCDuotone 属于"练手件"，不是"补空白件"。 这条我主动交出来，别等调研员捞到再翻。下一件必须避开这个坑。

1. 候选一（建议先批）：DCLineBoil — 线条沸腾 / 手绘抖动

一句话：让干净的矢量线条每帧轻微形变，出"手绘逐帧画"的沸腾感（2D 手书/动画的 line boil）。

为什么用户用得上：用户本职是 PV/手书/剪辑。手书最怕线条"太干净"——整齐划一的线条像矢量图，不像手画。 现在唯一办法是给每条线加 wiggle 表达式，几十个图层就是灾难；或者逐帧手画。

未装证据（.aex 层 790 件）

  • boil 命中 0
  • jitter 命中 3 件，全是整体位移/跳帧：BCCJitter、BCCJitterBasic（整体位移抖动）、S_JitterFrames（随机跳帧），没有一件沿画面边缘做几何抖动
  • 脚本层 118 个 jsx 里最近的是「一键shake2.1」（整体镜头抖）、「Yan-K Glitch」（转场），都不是线条沸腾
  • AE 内置也没有（内置只有 Wiggle 表达式，是手写表达式不是效果件）

原创算法：单帧内用相邻像素亮度差近似局部梯度方向 → 用「帧号×坐标」哈希出的 value noise 生成位移向量 → 沿梯度方向做亚像素偏移采样（双线性）。纯 CPU、无历史帧、无 GPU。 参数：强度 / 速率（每几帧换一次种子）/ 尺度 / 边缘保护。

工作量：1 轮编译能到可用，v1 不需要 UI。

2. 候选二：DCInkBleed — 墨迹渗透 / 线稿湿边

一句话：把笔画边缘向外做不均匀"洇开"，用纸纤维噪声调制渗透强度，让线稿、字幕、标题字有沾水纸感。

为什么用户用得上：手书封面、PV 标题字、纸质风格片头。现在只能靠叠加贴图或用遮罩手糊。

未装证据

  • bleed 命中 0；ink 命中 1 件 = Color Link（颜色关联，无关）
  • watercolor 命中 1 件 = BCCWaterColor（整幅水彩渲染风格，不是沿线条边缘的渗透）
  • 脚本层无同类

原创算法：小半径局部极值扩散（形态学 spread 的整数近似）得到"洇开半径场" → 坐标哈希噪声扰动半径 → 按原图 alpha/亮度做门限，只在笔画附近生效，避免整片糊。 参数：渗透量 / 半径 / 纤维噪声尺度 / 门限。

风险：与 BCCWaterColor 视觉上可能被认作同域，建议批复前请调研员过一眼。

3. 候选三：DCFocusLines — 漫画集中线

一句话：程序化生成放射状集中线（长短不一、中心留白、外缘收细），做冲击/紧张/爆炸感的叠加层。

为什么用户用得上：手书和 PV 的高潮镜头，集中线是标准语言；现在只能找素材叠或者手画。

未装证据

  • manga 0、speedline 0
  • streak 2 件：BCCStreakyLight、S_Streaks —— 都是光效/光条，不是线条生成
  • radial 10 件全是模糊/聚光/擦除转场（BCCRadialBlur、BCCRadialWipe…）
  • focus 6 件全是景深/虚焦（S_RackDefocus、S_SoftFocus…）
  • 脚本层无同类

原创算法：逐像素转极坐标 → 角度按 N 等分量化成"线槽" → 每个槽用哈希决定起始半径与长度 → 沿线槽做宽度衰减，边缘加抖动。纯生成器，不读源图也可用（可选读源图做遮罩）。 参数：线数 / 长度 / 宽度 / 中心半径 / 随机种子 / 边缘羽化。

4. 核盘命令（可复现）

$mc='C:\Program Files\Adobe\Common\Plug-ins\7.0\MediaCore'
$all=Get-ChildItem $mc -Recurse -File -Filter *.aex
foreach($kw in 'boil','bleed','ink','manga','streak','jitter','watercolor','focus'){
  '{0,-10} {1}' -f $kw, ($all | Where-Object { $_.BaseName -match $kw }).Count
}

实测输出：boil 0 / bleed 0 / ink 1 / manga 0 / streak 2 / jitter 3 / watercolor 1 / focus 6； 目录实测：Sapphire 285 件、BorisFX 478 件，合计 790 与盘点一致。
