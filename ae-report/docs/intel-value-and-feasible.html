④ 可行性评估 + 替代方案（一次性，保底稿）

  • .jsx（JS 脚本）：✅ 高可行。ExtendScript 公开文档齐全，clean-room 重写收费脚本的逻辑即可，法律与安全都稳。替代=自己写/开源平替。
  • .aep（工程预设）：✅ 可行。本质是工程文件，拆开看结构、用 Essential Graphics 自己做预设版即可。
  • .jsxbin（加密脚本）：⚠️ 中。可反编译查看逻辑（社区有 jsxbin 反编译器），但重写需 clean-room 重实现，不能照搬代码。替代=找同名免费开源实现。
  • .aex（C++ 插件）：❌ 低。需 AE SDK + C++ 编译，逆向闭源 .aex 法律与工程成本都高。替代=找开源同类插件或 FX 脚本平替。
