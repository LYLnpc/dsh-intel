二、逐条核对明细（GitHub 数据为 2026-11-14 API 实测）

1. Sapphire → Natron + craft-plugins

  • Natron：GPL-2.0，5,707 stars，最后推送 2026-07-24，活跃。开源节点式合成器，官方描述"功能类似 After Effects 与 Nuke"，内置 Glows、LensFlare、Grain、EdgeBlur 等 Sapphire 同类节点。
  • qwertyonek/craft-plugins：MIT，16 stars，最后推送 2026-10-11。README 自述受 Deep Glow、Quick Chromatic Aberration、Sapphire Shake、Displacer Pro 启发。注意：它是 WebAssembly 插件，宿主是开源合成器 EffectCraft，不是 AE 插件，只能作为"跨主机替代"。
  • 覆盖度：部分。AE 内不存在免费全功能 Sapphire 套件。

2. Magic Bullet Looks → DaVinci Resolve 免费版

  • 官网页面实测 HTTP 200。免费版即含节点式调色页、色彩轮、LUT 支持，覆盖 Looks（风格化调色）与 Colorista（二级调色）主功能。
  • 开源备份选项：Olive 编辑器（GPL-3.0，9,157 stars，最后推送 2024-12-05，更新趋缓）。
  • 覆盖度：部分（能力覆盖，工作流出 AE）。

3. Element 3D → Blender

  • blender/blender：21,959 stars，最后推送 2026-11-13，极活跃（许可证为 GPL-2.0+ 双许可，API 显示 NOASSERTION）。
  • 工作流：Blender 建模渲染（带 alpha 通道）→ AE 合成；另 AE 订阅自带 Cineware/C4D Lite 可在 AE 内直接接入 3D。
  • 覆盖度：部分。社区共识是没有免费插件能复刻 Element 3D 的 AE 内实时 3D 渲染。

4. Plexus 3 → Blender 几何节点 / AE 内置

  • Blender 几何节点可原生实现"点云 + 按距离连线"（Plexus 标志性效果）并真 3D 渲染。
  • AE 免费路线：CC Particle World、CC Ball Action 配 linear() 表达式做轻量版。
  • 覆盖度：部分。

5. Optical Flares → 内置 Lens Flare + CC Light Rays + Creation Lens Flares

  • Creation Lens Flares：经 WebFetch 实读页面确认价格为 $0（"This product costs nothing!"），是 AE 项目模板而非插件，无需安装第三方效果，兼容 AE 2021+。页面 HTTP 200。
  • AE 内置 Lens Flare、Glow、CC Light Rays 组合可重建大部分光晕效果。
  • 覆盖度：部分（Optical Flares 的实时交互光斑编辑器没有免费等价物）。

6. Deep Glow → openglow / LumenGlow / 内置 Glow

  • danilomdamiani/openglow：MIT，0 stars，最后推送 2026-10-12。"lightweight and GPU accelerated glow plugin for Premiere and After Effects"，真实存在、许可证干净，但极新、无社区验证。
  • JackBuzbuz/LumenGlow：0 stars，最后推送 2026-10-21。自述"physically based glow plugin for After Effects (Deep Glow-style bloom, iris bokeh, lens dirt, tone mapping, spectral chromatic aberration)"。新项目，未标注开源许可证，采用前需审阅。
  • 覆盖度：部分。Deep Glow 的物理衰减质感在上述项目中接近但未经大规模验证。

7. Flow → Bezier Curve_Editor + Rebound

  • Vergil1000x/Bezier_Curve_Editor：4 stars，最后推送 2025-04-23，无许可证标注。仓库描述即"Free After Effects extension to create and apply custom Bezier easing curves... Flow-like, but open-source!"。
  • meszmate/rebound：30 stars，最后推送 2026-08-16，活跃（自定义许可证 NOASSERTION，使用前读 LICENSE）。
  • 覆盖度：全替代（Flow 核心 = 曲线库编辑与应用，两项目合计覆盖）。

8. EaseCopy → eKeys + ivg-design/AE + Flow-State-Pack

  • motiondeveloper/eKeys：MIT，40 stars，最后推送 2023-03-04。关键帧缓动工具。
  • ivg-design/AE：MIT，22 stars，最后推送 2026-11-13，活跃。35 个免费脚本，覆盖关键帧/绑定/路径。
  • randomaistuff/Flow-State-Pack：1 star，最后推送 2026-02-16，含 Copy Keyframes 类扩展（项目极小，仅作备选）。
  • 覆盖度：部分。EaseCopy 的"复制缓动不改值、按新时长缩放"精细行为需逐个工具验证。

9. Motion 2 → Rebound

  • meszmate/rebound（同第 7 条）：30 stars，2026-08-16 活跃。自述"free easing & motion-design panel for After Effects"，除缓动外含锚点、对齐等工具，对应 Motion 2 的 mt_ 系列常用面板功能。
  • 覆盖度：部分。

10. GifGun → AEJuice Export GIF + ffmpeg

  • AEJuice Export GIF：页面实测 HTTP 200，官方定位免费（aejuice.com/product/export-gif/），从渲染队列一键导出 GIF，与 GifGun 主功能同型。
  • ffmpeg 开源兜底：AE 渲染视频后一行命令转 GIF。
  • 覆盖度：全替代。

11. AutoSway → Duik Ángela + 表达式方案

  • Duik Ángela（见第 12 条）提供骨骼与自动化工具，配合 wiggle/循环表达式作用于 Puppet Pin 是社区常用免费摆动方案。
  • 线索存疑项：搜索中提到免费脚本 "Fake Dynamic"（用途与 AutoSway 类似），但 GitHub 检索未找到可靠官方仓库，未能核实，暂不收录链接。
  • 覆盖度：仅近似。

12. RubberHose → Duik Ángela

  • RxLaboratory/Duik：GPL-3.0，408 stars，最后推送 2026-11-05，活跃。"Duik Ángela | Rigging and animation tools for After Effects"。Duik 本身免费（官方接受随意付费/捐助），源代码开源。
  • 多来源交叉印证：School of Motion 对比文、r/MotionDesign 社区讨论均将 Duik 视为 RubberHose/Limber 的免费平替。
  • 覆盖度：全替代（IK、骨骼、自动绑定功能集比 RubberHose 更大，风格化管状肢体用"骨骼+曲线"工作流实现）。

13. Joysticks n Sliders → Duik Ángela

  • JnS 的核心是姿势式头部/面部绑定；Duik 的控制器、自动绑定与骨骼系统可搭建同类型绑走，但不如 JnS 专用滑杆直观。
  • 覆盖度：部分。

14. Twixtor → slowmoVideo + Flowframes + 内置 Timewarp

  • slowmoVideo/slowmoVideo：GPL-3.0，641 stars，最后推送 2022-12-19（维护放缓但可用）。专用光流变速工具。
  • n00mkrad/flowframes：GPL-3.0，2,093 stars，最后推送 2026-05-20。RIFE/DAIN AI 补帧 Windows GUI。
  • AE 内置 Timewarp（像素运动）为零成本第一选择。
  • 覆盖度：部分。Twixtor 的运动矢量精细控制（分割、边缘处理）无免费等价。

15. Universe → Mixkit 免费转场模板

  • Mixkit 转场模板页实测 HTTP 200，43 个免费 AE 转场（zoom/glitch/split/slide 等），直接复刻 Universe 高频使用场景。
  • 覆盖度：部分。Universe 是 90+ 效果全家桶（含 Retro/VHS 类），免费侧只能按场景逐个凑。

  • 排除（盗版嫌疑）：GitHub 搜索出现 OwlWorkshop78/video-copilot-optical-flares-offline-installer，为收费插件"离线安装包"仓库，判定盗版分发风险，不收录。
  • 失效链接：
  • videocopilot.net/products/saber/ → 404。Saber 免费插件的现行有效入口为发布博文页（HTTP 200）：videocopilot.net/blog/2016/03/new-plug-in-saber-now-available-100-free/（Saber 仍免费，可作 Glow/能量类免费补充）。
  • videocopilot.net/downloads/ → 404。
  • rainboxprod.coop、duik.rxlaboratory.com、premation.com → 本网络环境无法连通（000），Duik 一律引用 GitHub 仓库链接（已验证）；Premation 未收录。
  • WebFetch 对 github.com 直连失败（ECONNRESET），全部改用 GitHub REST API 核实，数据可信度等同或更高。
  • 低可信度标注：openglow、LumenGlow、Flow-State-Pack、Bezier_Curve_Editor 均为低 star（≤4）或 0 star 项目，真实存在但缺社区验证，采用前建议试装。

五、结论摘要

  1. 15 组对照全部成行（超过 12 组要求），其中全替代 3 组（Flow、GifGun、RubberHose→Duik），部分 9 组，仅近似 3 组（AutoSway、及按定义计入的跨主机方案）。
  2. 绑定类（RubberHose/JnS/AutoSway）免费侧收敛于 Duik Ángela（GPL-3.0、活跃、社区公认平替）；缓动类收敛于 Rebound + Bezier Curve_Editor；变速类为 slowmoVideo + Flowframes；调色类出 AE 用 Resolve 免费版；3D/点线类用 Blender。
  3. AE 原生免费插件级替代中最值得盯的两个新项目：openglow（MIT）与 LumenGlow（Deep Glow 风格），均为 2026 年 10 月仍在推送的新仓库，缺验证但方向正确。
