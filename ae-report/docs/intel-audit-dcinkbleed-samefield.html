二、命中清单与本域判定

装件干什么与 InkBleed 的关系
BCCWaterColor整幅图渲染成水彩不同域。它是"整张图变水彩"，InkBleed 是"只在线稿边缘向外洇"，作用范围与判据都不同
BCCEdgeGrunge对边缘做旧/破碎纹理最接近的同域件。同为"支棱边缘"，但 grunge 是叠加做旧纹理、不分笔画内外；InkBleed 的核心是「alpha/亮度门限 + 沿法线渗出」
S_Grunge / BCCGrunge全幅做旧纹理相邻。整幅叠加，不作边缘方向扩散
S_TextureNoisePaint噪声纹理绘画相邻。噪声是"纹理"不是"渗透半径场"
BCCSprayPaintNoise喷涂噪声相邻。喷溅形态，非湿边
Smear / Smear_New / Smear Blur沿运动方向涂抹不同域。涂抹有方向拖尾、不贴边缘法线
S_AutoPaint / S_CartoonPaint / S_DissolveAutoPaint / PaintBucket自动上色 / 卡通化 / 填充不同域（上色，不是边缘形变）
3DStroke / Stroke / VectorPaint / DCStroke描边与矢量绘制不同域（生成线条，不改造已有线条边缘）
BCCWaterWaveDissolve / BCCWaterWavesDissolvePrTr水波溶解转场无关（转场类）
Color Link / ColorLink颜色关联无关（原生工已正确排除）

bleed / ink / fiber / paper 独立关键词：0 命中（ink 唯一命中是 Color Link，无关）。

三、结论

判定：可以做，但必须收窄范围，且 README 写清与 BCCEdgeGrunge 的差异。

  1. 不撞 BCCWaterColor（原生工自己担心的那件）。两者虽都属"水彩/湿"语汇，但一个是整幅风格化，一个是局部边缘形变，用户拿它们做的是两件事。
  2. 真正的同域件是 BCCEdgeGrunge——这是本审查的新发现，原生工和指挥都没点到。它同样"支棱边缘"。差异在判据：grunge 是向边缘叠加噪声纹理（改的是质感），InkBleed 是按笔画 alpha 门限向外扩散半径（改的是轮廓形状）。这个差异是真的，但边界不算宽。
  3. 残留不确定：只看文件名无法确证 BCCEdgeGrunge 的具体行为（参数是否含"向外扩散量"）。此点标 未核实细节，需要看它的效果控件才知道。建议不为此安装测试——按"不改动本机已装件"的红线，不追加操作。
  4. 3 大厂内核不碰：BCC / Sapphire 的行为比对只作为"是否重复"的判断依据，不读取、不复制任何算法。

四、给原生工的收窄建议（若指挥批）

  • v1 只做一件事：按源图 alpha（无 alpha 用亮度）求门限 → 只在该门限内、沿局部梯度法线向外做单尺度亚像素扩散 → 用坐标+帧号哈希噪声调制扩散量。
  • 不要做整幅水彩化、不要做多色扩散、不要做纸张底纹叠加（那三样会直接落进 BCCWaterColor / BCCEdgeGrunge / S_TextureNoisePaint 的地盘）。
  • README 里必须写一句：「本件与 BCCEdgeGrunge 的区别 = 改轮廓形状 vs 改边缘质感；若你只是要边缘做旧，用已装的 BCCEdgeGrunge 即可，不必装本件。」
