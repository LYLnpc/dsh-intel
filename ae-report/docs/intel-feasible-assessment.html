三、其他不可行/降级项（任务书范围外的诚实声明）

  1. jsxbin 加密脚本黑盒复刻 → 降级为「功能对照 + 复刻思路」，不硬啃（加密字节码不可 clean-room 还原）。
  2. Overlord 完整双向（Ai 端实时联动）→ 需 Illustrator 端 CEP 扩展，纯 jsx 无法实现另一半；已交付单向 SVG→AE 版（含参数化形状、comment 回写更新、自写解析器 29 项断言）。
  3. Move Anchor Point v4 的 aex 形态 → 逻辑层 jsx 完全可实现，已交付 jsx 版（3×3 吸附 + toComp 差分补偿）；"一键裁剪 comp 到内容"经查证为情报混淆（疑与 Motion Tools Pro 混淆），已从范围剔除并勘误 paid-list §29。
  4. AE 实机自动化验证 → 环境无 AE 无人值守接口，复刻件只能做到静态验收（API 白名单逐字对照 + node --check + ES3 扫描 + 数学/解析器离线断言）；最终冒烟需用户实机执行 docs/smoke-test.md。
  5. LineBoil → aescripts 上不存在同名商品（已核实），"线条沸腾"有免费原生做法（Turbulent Displace 打帧 + Hold）；如需脚本化属 A 类需求池，未纳入本轮。
  6. B 类 2 件（Deep Glow 2 / Hawaiki Keyer 5）→ 按既定策略给原生近似路线（多层 Glow 组合 / Keylight+Key Cleaner+Spill Suppressor 内置三件套），不作为独立复刻件。
