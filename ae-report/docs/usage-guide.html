## 0. 安装公共流程（先看这节，下面每节只讲差异）

所有 21 个工具都是**单文件 `main.jsx`**，安装方法相同：

1. **决定运行方式**
   - **可停靠面板（推荐）**：把 `main.jsx` 拷进 AE 脚本面板目录：
     - Windows：`C:\Program Files\Adobe\Adobe After Effects <版本>\Support Files\Scripts\ScriptUI Panels\`
     - macOS：`/Applications/Adobe After Effects <版本>/Scripts/ScriptUI Panels/`
     然后**必须重启 AE**，在菜单 `Window`（窗口）**最底部**找到以**文件名**命名的条目勾选。
   - **临时运行**：`File > Scripts > Run Script File...` 选 `main.jsx`——弹出浮动窗口，**不能停靠**，关闭即退出。
2. **常见坑**
   - **目录拷贝要管理员权限**：`Program Files` 下的目录 Windows 默认写保护，右键"以管理员身份"打开资源管理器或先拷到桌面再拖进去。
   - **必须重启 AE**：ScriptUI Panels 目录的脚本只在 AE 启动时扫描，拷完不重启 = 菜单里找不到。
   - **面板名 = 文件名**：面板菜单显示的是文件名，21 个工具都叫 `main.jsx` 会撞名分不清——**建议分别重命名**。第一批：`FlowClone.jsx`、`EaseCopyClone.jsx`、`TCDupClone.jsx`、`GifGunClone.jsx`、`ASSpringClone.jsx`、`JNSClone.jsx`、`M2Clone.jsx`、`TwoBoneIKClone.jsx`；第二批（见各节安装差异）：`EAWClone.jsx`、`KeyTweakClone.jsx`、`AGClone.jsx`、`SliceItUpClone.jsx`、`RollItClone.jsx`、`EasyBakeClone.jsx`、`KMClone.jsx`、`EaseStashClone.jsx`、`RowsColsClone.jsx`、`ParrotClone.jsx`、`SquirrelClone.jsx`、`AddSauceClone.jsx`、`WobbleBoxClone.jsx`。
   - **中文乱码不影响功能**：部分复刻的 main.jsx 为 UTF-8 带 BOM（正常显示中文），个别为纯 ASCII（界面英文）。若打开源码看到注释乱码，是编码问题不影响运行；UI 文字乱码则只影响阅读不影响逻辑。
   - **脚本安全设置**：`Edit > Preferences > Scripting & Expressions` 勾选 **Allow Scripts to Write Files and Access Network**。21 个工具中有 4 个真的需要写文件：GifGun Clone（app.settings 记忆偏好 + 临时序列帧）、Flow Clone（命令行模式写 flc-cli-log.txt）、Ease Stash Clone（预设库 presets.json）、Add Sauce Clone（捆绑库 .sauce 文件）；其余不写文件，勾不勾都能跑，但勾上可免首次运行的安全提示打断。
   - **表达式安全**：AS Spring / JNS / M2 / TwoBone IK 会给属性写表达式；第二批的 Roll It（表达式模式）、Parrot、Again!、WobbleBox 同样写表达式（KeyTweak/KeyMaster/Easy Bake 等只改关键帧不写表达式）。新旧 JS 表达式引擎（文件 > 项目设置 > 表达式）都兼容（表达式按 ES3 写法生成），但在 Legacy 引擎上性能未实测。
3. **undo 习惯**：全部工具的修改操作都包在 Undo 组里，一次 Ctrl+Z 整体撤销——试参数时放心点，不满意就撤。

## 1. Flow Clone（flow-clone）—— 缓动曲线预设库

### 1.1 它解决什么问题

PV/手书里"动画手感"九成取决于关键帧缓动：默认线性/缓入缓出看着廉价，手调速度图又慢。Flow Clone 内置 16 条预设曲线，选中关键帧一键套用，再用强度/速度两个旋钮微调，让位移、缩放、透明度的起停手感快速统一。它不改关键帧的值，只改 ease。

### 1.2 安装步骤详解

公共流程照第 0 节走，本工具差异点：

1. 建议重命名为 `FlowClone.jsx` 再放入 ScriptUI Panels 目录，重启 AE。
2. 本工具有**命令行/无头模式**（加分项，原版没有）：AE 启动参数带 `--flc-preset=<名> --flc-intensity=1.5 --flc-speed=1.0` 时，启动即对所有选中关键帧应用并写 `flc-cli-log.txt`（与脚本同目录）——**此模式需要勾选"允许脚本写文件"**。日常面板使用用不到。
3. 也暴露了脚本 API：ExtendScript 控制台里 `$.global.flcApplyPreset("Ease Out - Strong", 1.5, 1.0, true)` 与 `$.global.flcListPresets()` 可供别的脚本调用。
4. **未实机验证，建议先在测试工程试**（曲线预览依赖 ScriptUI graphics，个别 AE 版本画不出来会静默降级为文字，属已知防护）。

### 1.3 参数逐个详解（以下基于源码推导）

**16 条预设**（下拉选择，默认选中第 9 项 "Ease Out - Medium"）：Linear(参照) / Smooth Light/Medium/Strong（缓入缓出，强=陡 S 曲线）/ Ease In Light/Medium/Strong（慢起快收）/ Ease Out Light/Medium/Strong（快起慢收）/ Snappy Light/Strong（快出急停）/ Overshoot·Spring·Bounce 类（见下）。贝塞尔预设的控制点表见该目录 README。

**Intensity 强度（滑杆 20–300，即 0.2–3.0，默认 1.00）**：把手柄相对段角点的偏移量按 k 缩放。**调大（>1）**：曲线更"激进"——缓入更晚动、缓出更快到位；**调小（<1）**：趋向线性。上限受两道钳制：手柄 y 值被夹回 [0,1]，且出影响度+入影响度总和 ≤ 约 100%（超出时等比收缩），所以拉满后曲线可能比预设名义形状"温和"，属 AE 限制不是 bug。

**Speed 速度（滑杆 20–300，即 0.2–3.0，默认 1.00）**：把手柄的时间跨度除以 s。**调大**：响应更快、过渡更短促（snappier）；**调小**：过渡铺得更开。对 Overshoot/Spring/Bounce 类，Speed 改的是振荡频率（越高来回越快），Intensity 改的是阻尼（越高振幅越大）。

**"No keys selected: use all keys..."（勾选框，默认开）**：时间线上没选关键帧时，对该属性**全部**关键帧生效（兼容不支持 selectedKeys 的旧版 AE）。**不勾**则没选键就什么都不做。

**应用规则**：相邻选中的**两个**关键帧=整段曲线（起键写 out-ease、末键写 in-ease）；**单个**关键帧=入方向用曲线后半段、出方向用前半段成形；Overshoot/Spring/Bounce **必须同时选中一段的两端关键帧**——因为两个关键帧之间的 temporal ease 无法表达数值过冲，这类预设靠逐帧采样插入中间关键帧实现，会先清掉该段旧中间键，可安全重复应用。

### 1.4 三个演示场景

1. **PV 歌词入场统一手感**：文字层 position 已打"出现"两键 → 时间线同时选中这段的**两端**关键帧 → 下拉选 "Ease Out - Medium" → Apply。预期：状态行显示应用数量，预览小图显示所选曲线；关键帧值不变，出方向变缓出手感。
2. **弹跳球落地过冲**：球 position 的下落段两端关键帧选中 → 选 "Overshoot" 或 "Spring" 类 → Intensity 1.5 → Apply。预期：两键之间多出一条条逐帧中间关键帧、数值越过终点再回弹；删除中间键重新调 Speed 可改回弹节奏。
3. **MG 快切节奏**：图标 scale 两键 → "Snappy - Strong" + Intensity 1.8 → Apply。预期：几乎瞬间到位后急停；对比 Intensity 0.5（趋向线性）感受差别。

### 1.5 常见问题

1. **Overshoot/Spring/Bounce 点了没反应？** 这类预设只对"选中一段的两端关键帧"生效，单选一个键会被跳过并提示——设计如此（插帧需要段）。
2. **曲线和预设名说的不一样"软"？** Intensity 拉满触发了 AE 手柄约束钳制（y∈[0,1]、影响度和 ≤100% 自动等比收缩），把 Intensity/Speed 回到 1 附近对照预览小图排查。
3. **面板里曲线预览是空白的？** ScriptUI graphics 在个别 AE 版本不可用，工具会静默降级为文字——不影响应用功能。另注：整份复刻未实机验证，建议先在测试工程试。

### 1.6 与原版差距（一句话）

没有可拖拽的曲线可视化编辑器和自定义预设保存/加载/分享，spring/bounce 用"插中间帧"而非原版贝塞尔近似实现。

## 2. EaseCopy Clone（easecopy-clone）—— 缓动复制粘贴

### 2.1 它解决什么问题

调好一段完美的缓动后，想让全片几十个关键帧都用同一种手感：AE 原生复制会连数值一起带走。EaseCopy Clone 只复制 ease（speed+influence）、不碰关键帧值；还支持把一整段动画（时间+值+缓动）拷走，粘贴时按目标跨度自动缩放时长。PV 客户改稿、批量统一动画手感时最省时间。

### 2.2 安装步骤详解

公共流程照第 0 节。差异点：

1. 本工具 main.jsx 为**纯 ASCII**（界面英文），不依赖编码，任何 AE 版本打开源码都不会乱码。
2. 重命名为 `EaseCopyClone.jsx` 放入 ScriptUI Panels，重启 AE；或 Run Script File 浮动运行。
3. **注意生效范围**：所有操作只对**时间线里被选中的属性**（点属性名选中，`comp.selectedProperties`）生效——只选中图层而没选中属性时按钮会提示让你选属性。
4. **未实机验证，建议先在测试工程试**。

### 2.3 参数逐个详解（以下基于源码推导）

**In only / Out only（勾选框，默认都不勾）**：拷贝方向过滤。**只勾 In only**：Copy 时只记录关键帧的入方向 ease；**只勾 Out only**：只记出方向；**都不勾或都勾**：入+出都记。粘贴时只覆盖被记录的一侧，另一侧保留目标关键帧原有的 ease（源码用 keyTemporalEase 回读当前值再回写）。

**Slot 1–4（四行 Copy N / Paste N / 状态文字）**：4 个独立槽位。**Copy N**：把**第一个**选中关键帧的 ease 存进槽 N（多选时只取第一个，设计如此）；**Paste N**：把槽 N 应用到**所有**选中关键帧。行内状态文字显示槽位内容，如 "2D, in+out | in spd 120 inf 66"——维度、方向和首维的 speed/influence 一目了然，方便对齐"我要的是哪份缓动"。**粘贴时按目标属性的维度重建 ease 数组**：维度缺失回退到源末维、1D→nD 复制该值、nD→1D 取第一维（跨属性粘贴是近似行为）。

**Copy Animation / Paste Animation（整段动画）**：Copy Animation 要求**选中属性**（点属性名），记录全部关键帧的相对时间、值、入/出插值类型与 ease，状态行显示 "stored: N prop(s), M keys, span X s"。Paste Animation 要求**选中目标属性上用来定义新时间跨度的关键帧**：缩放比 = 目标首尾键跨度 ÷ 源跨度；**关键帧时间 ×scale、ease speed ×(1/scale)、influence 不变**（拉伸后速度感一致）。只选一个键（跨度 0）或源只有一键时按原时长 1:1 从该键位置开始写。多目标按选择顺序映射到第 i mod N 个源属性（目标多于源时循环复用）。

### 2.4 三个演示场景

1. **PV 全片统一缓动**：调好歌词位移后，选中源层 position 的第一个关键帧 → `Copy 1` → 依次选中其他歌词层的属性和关键帧 → `Paste 1`。预期：槽位行显示 "2D, in+out | …"；所有选中键的手感变成与源一致，数值完全不动。
2. **只取"急停"不要"慢起"**：勾 `Out only` → 选中源键 → `Copy 2` → 选中目标键 → `Paste 2`。预期：目标键出方向变成源的急停曲线，入方向保持目标原有缓动。
3. **一段开场动画复制到片尾并改时长**：源属性点属性名选中 → `Copy Animation`；目标属性上选两个关键帧定义新跨度（比如 3 秒→1.5 秒）→ `Paste Animation`。预期：弹窗 "Time scale: 0.5x (ease speed x2)"——关键帧压缩一半、缓动速度加倍，节奏等比。

### 2.5 常见问题

1. **重启 AE 后槽位空了？** 槽位只在内存，跨会话持久化未复刻（README 明示）——重要缓动用 4 个槽位当场用完。
2. **Paste Animation 后时间线上多出乱七八糟的键？** 整段粘贴是**叠加**而非替换：不删除目标区间里已有的其他关键帧，先手动清掉目标区间旧键再粘。
3. **有些键贴了没反应？** Hold 关键帧 AE 会拒绝写入 ease（工具按计数跳过，hold 状态本身通过插值类型还原）；influence 会钳制到 AE 接受范围 [0.1, 100]；shape 路径等不可重定时属性整条跳过并计数提示。

### 2.6 与原版差距（一句话）

没有槽位跨会话持久化、曲线可视化与预设库，多目标粘贴是循环配对而非智能匹配。

## 3. True Comp Dup Clone（true-comp-dup-clone）—— 合成树整体复制

### 3.1 它解决什么问题

客户说"换个颜色/换个角色再出一版"：AE 自带复制只复制单个 comp，子合成还是原来那条——改新版本会污染旧版本。True Comp Dup Clone 从选中的合成出发，把整条依赖链（嵌套预合成闭包，可选含 footage）复制成带递增后缀的新副本并重接好引用，模板多版本化一次到位。

### 3.2 安装步骤详解

公共流程照第 0 节。差异点：

1. 重命名为 `TCDupClone.jsx` 放入 ScriptUI Panels，重启 AE；或 Run Script File 运行（推荐后者，一次性工具）。
2. main.jsx 为 UTF-8 带 BOM，界面中文正常显示；工具不写文件，不用勾"允许写文件"。
3. **使用前置**：先在**项目面板**选中 1 个或多个要复制的合成（CompItem），再运行——面板打开时快照当前选中项，面板内可点「刷新选中」重新抓取。
4. **未实机验证，建议先在测试工程试**（尤其含表达式、轨道遮罩、父级的复杂工程）。

### 3.3 参数逐个详解（以下基于源码推导）

**计数预览行**：实时显示"已选 N 个根 comp，将复制 M 个 comp（含依赖闭包）"——M 会随排除项和 footage 勾选实时重算，导出前先看这个数心里有数。

**名称后缀（默认 `" 2"`，即 AE 自带复制惯例）**：副本名 = 原名+后缀。工程里已有同名时自动追加递增编号（`X v2 2`、`X v2 3`…），所以多个同名的 comp 一起复制也不会互相覆盖。后缀留空则副本与原名相同+递增编号。

**同时复制 footage 素材（勾选框，默认关）**：**关**：闭包内引用的 footage/solid 共享原素材（副本引用原文件，最省工程体积）；**开**：每个引用到的素材也 `duplicate()` 一份加后缀（共享同一源文件路径），镜像进同名文件夹。

**镜像原始文件夹结构（勾选框，默认开）**：**开**：副本放进按原 parentFolder 链重建的同名文件夹树；**关**：全部落在工程根。

**排除列表（点击条目切换 ✓ 标记）**：被排除的 comp **不复制也不递归**——引用它的图层在新副本里保持指向原 comp（共享）。用途：某个子 comp 是"全工程共用组件"（如统一的背景层）时不希望被复制。点错的用「清除排除」一键清空。

**创建副本（按钮）**：按"依赖在前"的顺序逐个复制（addComp 同宽高/帧率/时长/像素比，图层走 copyToComp 保真复制，再 replaceSource 重接引用、按原 index 重接父级）；完成后弹窗汇总（复制了几个 comp、几个素材、根副本名、警告列表），并自动选中**新根 comp**。一次 Ctrl+Z 整体撤销。

### 3.4 三个演示场景

1. **客户要"红色版+蓝色版"**：项目面板选中主 comp `MAIN_v1` → 运行 → 预览显示"将复制 5 个 comp"→ 后缀填 `" 红色版"` → 创建副本。预期：项目面板出现 `MAIN_v1 红色版` 及其 4 个子合成副本（原名+后缀），镜像文件夹整齐排列，新根 comp 自动被选中打开；进副本改颜色不会影响原版。
2. **共用组件不复制**：列表里点击 `通用背景` 标 ✓（预览计数 -1）→ 创建副本。预期：新主 comp 里引用背景的那一层仍指向**原** `通用背景`——改一次背景，两版同时变。
3. **工程交付要连素材一起带走**：勾「同时复制 footage」→ 预览计数多出素材数 → 创建副本。预期：弹窗显示"创建 N 个 footage 副本"，素材面板出现同名+后缀的素材副本，方便按副本树整体打包。

### 3.5 常见问题

1. **副本里的表达式失效了？** 表达式字符串是**原样带过**的（设计如此）：表达式里 `comp("旧名")` 按名引用时，副本改名后仍指向原 comp。规避：后缀留空、或表达式用 thisComp/index 引用。
2. **复制的层顺序/轨道遮罩不对？** copyToComp 在不同 AE 版本的插入位置（顶部/底部）不同，工具会自动探测并用 moveAfter 链修正；极端情况下两个完全同名的图层可能发生歧义（内容相同，只有轨道遮罩配对可能受影响）——遇到就手动对调一次。
3. **警告列表里出现"调整层"相关错误？** 极老版本 AE 走逐属性回退路径时，无 source 的调整层用"新建 solid + adjustmentLayer"实现，会多出一个白色 solid 素材项——功能不受影响，删掉即可。

### 3.6 与原版差距（一句话）

没有正则搜索替换命名、不重写表达式里的 comp 名引用、不保留代理（Proxy）设置。

## 4. GifGun Clone（gifgun-clone）—— 一键 GIF 导出

### 4.1 它解决什么问题

给客户发动态预览、给 B站投动态宣传图，AE 原生导 GIF 要渲染队列+外部工具七手八脚。GifGun Clone 把"渲染 PNG 序列 → ffmpeg 两遍法合成高质量 GIF"串成一键：工作区/全时长、帧率、宽度、质量都参数化，GIF 色彩质量（palettegen/paletteuse 全局调色板）明显好于单遍直转。

### 4.2 安装步骤详解

公共流程照第 0 节。差异点：

1. 重命名为 `GifGunClone.jsx` 放入 ScriptUI Panels 重启 AE；或 Run Script File 运行。
2. **必须先装 ffmpeg**（这是唯一的外部依赖）：下载见 https://ffmpeg.org/download.html （Windows 推荐 gyan.dev / BtbN builds，macOS `brew install ffmpeg`）；放到**脚本 main.jsx 同目录**、或加入系统 PATH、或在面板"ffmpeg路径"框里填完整路径。验证：命令行 `ffmpeg -version` 有输出即可。
3. **必须勾选"允许脚本写文件"**（写临时序列帧与 app.settings 偏好）。
4. **未实机验证，建议先在测试工程试**；ffmpeg 检测以命令输出含 "ffmpeg version" 为准，极个别环境误判时在路径框手动指定即可绕过。

### 4.3 参数逐个详解（以下基于源码推导）

**GIF 帧率（滑杆 8–30，默认 15）**：GIF 的播放帧率。**调大**：更顺滑、文件更大；**调小**：更卡顿但体积小。注意实现原理：渲染仍按合成**原始帧率**输出全帧序列，GIF 帧率由 ffmpeg `fps` 滤镜均匀抽帧——所以滑杆不动你的合成。

**最大宽度（输入框，默认 640）**：GIF 输出宽度上限，lanczos 重采样、高度自适应取偶；**填超过合成宽度的值**自动取合成宽度（不放大）。

**质量（滑杆 1–5，默认 4）**：映射调色板颜色数与抖动方式。**5**：256 色 + sierra2_4a 抖动（观感最好，稍慢）；**4**：256 色 + bayer_scale=2 同族；**3**：256 色 + bayer_scale=3；**2**：128 色 + bayer_scale=4（体积明显变小）；**1**：64 色 + bayer_scale=5（极小体积，色彩断层可见）。

**仅渲染工作区（勾选框）**：勾 = 只渲染 AE 时间线工作区（workAreaStart/Duration）；不勾 = 全时长。工作区无效时自动回退全时长。

**保留序列帧（勾选框，默认关）**：**开**：成功后保留临时 PNG 序列（可拿去手动转别的格式）；**关**：成功后自动清理临时目录。

**输出目录**：默认工程文件所在目录（工程未保存则桌面），「...」浏览选择；同名 GIF 自动加 `_1/_2` 不覆盖。

**ffmpeg路径**：留空 = 自动检测（用户上次填的路径 → 脚本同目录 → 系统 PATH）；填了就优先用填的。

**一键导出 GIF（按钮）**：全流程 = 检测 ffmpeg → 建临时目录 → 渲染队列出 PNG 序列（AE 自带进度可见）→ palettegen 生成全局调色板 → paletteuse 合成 GIF（`-loop 0` 无限循环）→ 自动打开输出目录，状态行显示成品信息。

### 4.4 三个演示场景

1. **B站投稿动态预览**：合成里设好 3 秒工作区 → 勾「仅渲染工作区」、fps=15、宽度=640、质量=4 → 一键导出。预期：AE 渲染进度跑完（约 90 帧序列）→ 状态行"第一遍/第二遍"→ 输出目录自动打开，得到 15fps、640px 宽、无限循环的 GIF。
2. **没装 ffmpeg 的同事机器上**：ffmpeg 检测失败 → 不合成，弹窗给出已导出的帧数与目录、附手动转换命令行（`ffmpeg -framerate … -i frame_%05d.png out.gif`）并自动打开帧目录，序列帧已保留。
3. **客户要高质量小样**：质量拉到 5、宽度留合成原生宽 → 一键导出。预期：256 色 + sierra2_4a 抖动、全尺寸，观感明显优于质量 1（64 色 bayer），文件也大数倍——发给客户用 5，群里预览用 1。

### 4.5 常见问题

1. **点导出后 AE 卡住不动？** 渲染与 ffmpeg 调用是**同步**的（后台渲染未复刻），期间 UI 冻结属正常——渲染阶段 AE 自带进度可见，看它跑完即可。另外渲染队列里**已有的排队项会被一并渲染**（render() 渲染整个队列），导出前清掉别的排队项。
2. **渲染完提示"没有序列帧"？** 工程里缺 PNG Sequence 类输出模块模板（AE 默认自带，可能被清理过）——按弹窗指引到 `编辑 > 模板 > 输出模块` 恢复，或重装/换台 AE。
3. **每次导出渲染队列多一项？** 脚本 API 无法移除渲染队列项（AE 限制），导出会在队列里留下已渲染项，手动清；导出失败时弹窗会带 ffmpeg 命令与输出尾部，方便排查（常见：路径含特殊字符、ffmpeg 版本太老没有 palettegen）。

### 4.6 与原版差距（一句话）

只有 GIF 一种输出（无 WEBP/WEBM/MP4），同步渲染会锁 UI（无后台渲染），也没有队列管理与快捷键集成。

## 5. AS Spring Clone（autosway-clone）—— 弹簧摆动链

### 5.1 它解决什么问题

头发、绶带、尾巴、树枝这类"柔性元素"的二次摆动，手 K 每一层是噩梦。AS Spring Clone 对**按顺序选中的一串图层**一键生成弹簧表达式链：根层被风力/关键帧驱动，摆动量按比例逐层向后传导并自然滞后——Verlet 弹簧方程离散化实现，参数全部挂成效果滑杆可随时调。

### 5.2 安装步骤详解

公共流程照第 0 节。差异点：

1. 重命名为 `ASSpringClone.jsx` 放入 ScriptUI Panels 重启 AE；或 Run Script File 运行。
2. **选择顺序就是链方向**：时间线中**自上而下**的选中顺序 = 链的根→梢（最上层是链根）；Apply 前检查图层顺序。
3. Remove 按钮可整体移除：清掉表达式并删除所有 `AS:` 前缀效果。
4. **未实机验证，建议先在测试工程试**（valueAtTime 递推的开销与新旧表达式引擎差异是实机重点观察项）。

### 5.3 参数逐个详解（Apply 后每层效果控件里都有同名效果，可逐层改）

以下为面板默认值与调参方向（**基于源码与数学推导**）：

- **AS: Stiffness 刚度 k（默认 150）**：弹簧追目标的劲头。**调大**：跟得越紧、振荡越快（频率 ∝ sqrt(k/m)）；**调小**：软塌塌地慢慢跟上。极端值（k > 2.25·m/dt²）会被表达式自动收缩到稳定域，表现为"突然变软"——那是稳定性保护不是 bug。
- **AS: Damping 阻尼 c（默认 8）**：**c=0** 等幅振荡永不衰减；**调大**：很快停稳。物理判据 c < 2·sqrt(k·m) 为欠阻尼（会过冲回弹），超过则不回弹直接滑到位。
- **AS: Mass 质量 m（默认 1）**：越大越"笨重"（同 k 下响应慢）。一般不动。
- **AS: Wind Strength 风力（默认 8）**：摆幅。旋转模式单位是**度**，位置模式是**像素**；**负值 = 反方向**。想要安静绑定价调 0，纯靠 Base 关键帧驱动。
- **AS: Wind Frequency 风频（默认 0.5）**：风的周期性。默认单位**按秒（Hz）**；勾选 `Freq per Frame` 后改为**每帧周期数**（做逐帧抖动风格用）。
- **AS: Inherit 传导%（默认 60）**：子层继承父层摆动量的比例。**调大**：链上摆动越传越猛；**调小**：梢部几乎不动；每层独立可调（做"越到发梢摆越大"就逐层递增）。
- **AS: Safety 单帧钳制（默认 30）**：稳定性保险丝——单帧位移/旋转超过该值（度/像素）被钳住。表达式炸了画面乱跳时调小它救场。
- **AS: Memory 历史帧（默认 120）**：弹簧递推的采样深度上限；超过该帧数历史（或开始不足 2 帧）时退化为静态目标（无弹簧效果）。**调大** 更长历史但更耗性能（valueAtTime 递归）。
- **AS: Base / Base Pos**：手动驱动入口。Apply 时工具会把图层**原来的旋转/位置状态（含关键帧时间与值）迁进来**当目标——给 Base 打关键帧就是手动驱动，弹簧自动追。

面板侧还有：**应用到（Rotation/Position 下拉，默认旋转）**——旋转模式驱动 2D rotation 或 3D zRotation，位置模式驱动 2D 位置（风沿 X 轴、**不支持 3D 层**）；**链深度（0=全部）**——只给前 N 层生成链。

### 5.4 三个演示场景

1. **角色头发随风摆（旋转链）**：时间线自上而下依次选中 发根→发中→发梢 三层 → Rotation 模式 → Apply。预期：每层多出 9 个 `AS:*` 效果、rotation 挂上表达式；把链根的 Wind Strength 调到 20，三层依次滞后摆动、发梢幅度最大（Inherit 60 逐层累加）。
2. **绶带位置飘动**：Position 模式选中绶带各段（2D 图层）→ Apply → Wind Strength 填 **-15**（反方向）。预期：各段位置沿 X 轴往复飘；把中段的 Inherit 提到 90，末端甩得更开。
3. **手动驱动做"被拨动"**：对已绑定的链，风力全调 0 → 给链根的 `AS: Base` 打一个从 0° 到 30° 的关键帧。预期：根层被关键帧驱动，整条链像被手拨动一样弹簧式跟摆，衰减由 Damping 控制。

### 5.5 常见问题

1. **Position 模式弹窗"暂不支持 3D 图层"？** 位置模式明确拒绝 3D 层（代码防护），改用旋转模式或关掉 3D。
2. **参数拉满后摆动突然"变软"？** Verlet 稳定域保护生效（a+2b<4 的自动收缩），极端 k/c 下有界收敛但手感变钝——把 k/c 调回正常区间，或用 Safety 钳制兜底。
3. **原有关键帧动画去哪了？** Apply 时原属性的关键帧（时间+值）被迁入 `AS: Base` 控件，但**缓动曲线不迁移**（README 明示）；不满意就 Remove（整体撤销）。

### 5.6 与原版差距（一句话）

不生成控制 Null（参数直接挂图层效果）、不支持 puppet pin/形状点链、没有重力项，风力方向只有正负/X 轴。

## 6. JNS Clone（joysticks-clone）—— 摇杆姿势插值

### 6.1 它解决什么问题

角色转头、眼球看方向、表情切换这类"四象限姿势"绑定：手写双线性插值表达式对每个属性又长又容易错。JNS Clone 一键生成 Joy 摇杆控制层（黄色矩形=插值边界、白圆=手柄），给选中的数值属性挂上四角双线性混合表达式——拖动 Joy 层位置，属性值就在四个角点姿势之间平滑过渡。

### 6.2 安装步骤详解

公共流程照第 0 节。差异点：

1. 重命名为 `JNSClone.jsx` 放入 ScriptUI Panels 重启 AE；或 Run Script File 运行。
2. 面板「帮助」按钮内置快速上手六步，忘了流程点它。
3. **重要（面板帮助里也写了）**：表达式用 `thisComp.layer(索引)` 引用 Joy 层——**之后删除/重排图层会让表达式错位**，绑定完尽量别再动层序。
4. **未实机验证，建议先在测试工程试**。

### 6.3 参数逐个详解（以下基于源码推导）

**Joy 控制层（下拉+刷新）**：选定充当摇杆的图层；名字含 "joy" 的层会被自动选中为默认。刷新按钮重读图层列表（绑定失败提示引用失效时先点它）。

**目标图层 + 选属性…（下拉+按钮）**：目标层下拉选图层；「选属性…」打开属性挑选器**多选**要绑定的数值属性（1D→Slider 角点、2D→Point 角点、3D/4D→按分量拆滑杆）；也可以不挑，直接在时间线选中属性后点绑定。**SHAPE 类（路径）属性被排除**，绑不了。

**插值边界（合成边界 / 自定义 + 左/上/右/下）**：Joy 层位置在此矩形内归一化为 u、v ∈ [0,1]。**合成边界**：整屏都是摇杆行程；**自定义**：填 4 个数字（校验"右>左、下>上、宽高 ≥1"），Joy 只在小区域内有效——适合"摇杆只在这一块区域响应"。出界自动钳制到边缘姿势。

**初始姿势=当前值（勾选框，默认开）**：绑定时把属性当前值写入 4 个角点——中性起步，之后只改想要变化的角。**关**则四角从 0 开始自己填。

**添加 EaseBias（勾选框）**：在 Joy 层加 0–100 偏置滑杆。**调大**：u/v 向 smoothstep S 曲线混合，**中性区域过渡更陡、边角区域更平缓**（无原版的曲线编辑，是简化近似）；0 = 纯线性双线性插值。

**绑定 → 生成表达式**：Joy 层效果栈里生成 `JNS|<属性名>|TL/TR/BL/BR` 四个角点效果（重名自动 `_2`），目标属性挂上表达式。**移除选中属性表达式**：只清表达式，`JNS|` 效果保留（要删在效果控件里手动删）。

### 6.4 三个演示场景

1. **角色头部朝向（转/偏移类 1D 属性）**：创建 Joy 控制层（合成边界）→ 目标层选头部层 → 选属性勾 rotation → 勾「添加 EaseBias」→ 绑定 → 拖 Joy 白圆到右上角，把 `JNS|Rotation|TR` 调成 15°，其余三角调 -5°。预期：拖 Joy 位置在屏内移动，rotation 在四个角姿势间双线性过渡。
2. **眼球看向四角（2D 属性）**：选属性… 勾眼球形状层的 position（2D）→ 绑定（初始姿势=当前值）→ 预期四个 `JNS|Position|TL/TR/BL/BR` 是 2D 点值，分别填眼球看向左上/右上/左下/右下时的偏移量，拖 Joy 即可"看四方"。
3. **限制摇杆行程**：边界选自定义，填左 800/上 400/右 1100/下 700 → 重建 Joy 控制层。预期：黄色矩形缩小到该区域，Joy 出界时属性钳制在边界对应的边缘姿势——防止误拖到全屏乱套。

### 6.5 常见问题

1. **绑定后拖动没反应/报错？** 表达式按**层索引**引用 Joy 层——绑定后删除或重排过图层就会错位；点「刷新」重试或删掉表达式重新绑定（先确认 Joy 层还在）。
2. **找不到我的属性？** 只能绑数值类属性（Slider/Point/颜色等按分量处理）；路径（Shape）被排除；Joy 层自己的位置有自环保护，不允许绑到自身。
3. **角点值改了但只有部分方向变？** 四个角点是独立值：改 TL 只影响左上象限附近——四个都调才有完整四象限；若只想要"中心↔边缘"效果，把四角设同一值即可。

### 6.6 与原版差距（一句话）

没有"5 个关键帧姿势层一键生成控制器"的原版流程（改为效果滑杆角点摆姿势），也没有无限姿势的 Sliders 系统、Switch Template、路径绑定与跨 comp 驱动。

4. **未实机验证，建议先在测试工程试**。

### 7.3 参数逐个详解（以下基于源码推导）

**Zone 1 · Smart Anchor Move（3×3 按钮网格 TL/TC/TR/ML/C/MR/BL/BC/BR）**：把选中图层的锚点移到**内容包围盒**（sourceRectAtTime，空图层回退图层宽高）的九宫格位置。核心是位置补偿：移动前后每个 position 关键帧时刻的**合成空间点保持不动**（toComp/fromComp 由引擎代算父级/旋转/缩放），所以 2D 层在任意父级链下补偿是精确的。跳过项：锚点本身有动画的图层（避免歧义）、3D、摄像机/灯光——状态行会列出谁被跳过及原因。

**Zone 2 · Keyframe Direction Tools**：
- **Dir > Rotation**：给 rotation 挂表达式——取 position 最近关键帧区间中点的速度向量，图元朝运动方向旋转（y 向下坐标系，0° 朝右、90° 朝下）；速度近零保持原值。**前提**：position 至少 2 个关键帧；表达式实时响应关键帧移动，**不需要重新生成**。
- **Speed > Squash**：给 scale 挂速度驱动的挤压拉伸表达式：拉伸系数 `k = min(|速度|×0.06, 60)/100`，`scale.x×(1+k)`、`scale.y÷(1+k)`（近似体积守恒）。两个常数 SQUASH_GAIN=0.06、SQUASH_MAX=60 写死在文件顶部——想要更夸张的挤压改源码这两个数。沿 x 轴固定拉伸（不做沿运动方向的合成）。

**Zone 3 · Spring Presets（mode / amp / freq / decay）**：给**选中的有关键帧的属性**（没选属性则回退到选中图层的 position，前提其有关键帧）挂衰减正弦后处理表达式：
- **elastic（过冲弹簧，默认）**：`值 + V·A·sin(2πFt)/e^(Dt)`，V = 进入该关键帧的速度——速度越大过冲越大。
- **bounce（单边反弹）**：用 |sin(πFt)| 近似触地不穿透的反弹。
- **pendulum（固定幅值摆动）**：不依赖速度，`值 + A·sin/e^(Dt)`；**amp 字段 1 单位 = 1000 度**（0.02 = 20°），适合 rotation。
- **amp 弹性系数（默认 0.03）**：**调大**甩得更远；**调小**几乎看不出弹簧。**freq 频率 Hz（默认 2.5）**：**调大**抖得越快；**调小**慢悠悠。**decay 衰减（默认 5）**：**调大**很快停；**调小**晃很久。改参数重新点 Apply 即覆盖旧表达式。

### 7.4 三个演示场景

1. **logo 绕自身中心旋转**：选中 logo 层 → 点九宫格 **C**。预期：状态行 "Anchor moved on 1 layer(s)"，锚点跳到内容中心而画面**纹丝不动**（position 有动画也逐键补偿）；此后旋转/缩放都绕内容中心。
2. **箭头沿轨迹转向**：箭头层 position 已 K 一条曲线路径 → 选层 → 点 **Dir > Rotation**。预期：rotation 挂上表达式，播放时箭头始终指向运动方向；挪动关键帧后朝向自动跟随。
3. **UI 弹窗的过冲落位**：弹窗层 scale 打两个关键帧（0→100）→ 时间线选中该属性（有键）→ mode 选 elastic、amp 0.05、freq 3、decay 4 → **Apply to selected keyframes**。预期：scale 到 100 后过冲到约 105 再弹回稳定；嫌晃得久 decay 调到 8。

### 7.5 常见问题

1. **点九宫格没反应/状态行说 skipped？** 图层是 3D/摄像机/灯光、或锚点自带动画（工具为避免歧义跳过）、或空图层无尺寸——状态行会写明每层被跳过的原因。
2. **Dir > Rotation 挂了但转不对？** 前提是 position 至少 2 个关键帧（表达式取速度）；速度近零区间保持原值属防护行为。

### 7.6 与原版差距（一句话）

没有 Motion 2 的 Ease 滑块（keyframeEase 批量写入）、Burst 放射图形、Clone 关键帧克隆与 Rig 父子绑定，只覆盖锚点/方向/弹簧三块思路。

### 8.1 它解决什么问题

### 8.3 参数逐个详解（以下基于源码推导）

**选层规则**：先选中**第 1 个 = 根关节层（髋/肩）**，再加选**第 2 个 = 末端控制层（脚/手）**；两层的**锚点即关节位置**（表达式用 toComp 换算，父化后也正确）。勾「交换根/末」可反转两者的角色。

**骨长（Auto 自动测量 / Manual 手动输入 + L1/L2 输入框，默认 100）**：**Auto**：L1=L2=当前根末距离 ×0.6（总长 1.2d，留出弯曲余量）——建好后还能在效果控件里改；**Manual**：直接用输入的 L1/L2。骨骼参数以 `IKC: L1`、`IKC: L2` 滑杆挂在 **IKC: Elbow** 层上。**调大**：肢体更长、可弯余量更大；**调小**：末端拖到超出可达域时会被钳到伸直状态（公式内置 d 钳制与 cosA 收敛保护，不会报错只会绷直）。

**弯向翻转（IKC: Bend Flip，勾选框）**：肘/膝朝哪一侧弯。勾选 = 朝另一侧（公式内角符号取反）；不勾 = 默认侧。建完后直接在 Elbow 层效果控件里切换。

**粗细（输入框，默认 30）**：Create Hose 时软管描边初始宽度，挂成 `IKC: Thickness` 滑杆——随时在 Hose 层效果控件里调；软管颜色固定深灰、圆头圆角。

**三个按钮**：**Create IK** 生成 `IKC: Upper`（位置跟随根关节层锚点、旋转 = atan2+acos 上层骨角）与 `IKC: Elbow`（位置 = 余弦定理肘/膝点、旋转 = 下层骨角）两个 Null；**Create Hose** 生成 `IKC: Hose` 形状层（根关节→肘→末端三点贝塞尔，切线系数定死 kEnd=0.35/kElb=0.5）；**Remove** 删除三个 IKC: 图层（用户 artwork 不动，父化随 Null 删除自动解除）。

**装配约定（关键，别漏）**：大腿/上肢 artwork **父化到 IKC: Upper**，小腿/下肢 artwork **父化到 IKC: Elbow**；且 artwork 要满足"旋转 0 时沿 +X 方向、锚点在关节"——素材不满足时先摆好素材再建 IK。

### 8.4 三个演示场景

1. **卡通角色手臂**：把"肩部"空层排第 1、"手掌"控制层排第 2，都选中 → Create IK（Auto）。预期：弹出参数确认（显示自动算出的 L1/L2），合成里多出 IKC: Upper 与 IKC: Elbow；把大臂图元父化到 IKC: Upper、小臂父化到 IKC: Elbow；拖手掌层 → 肘部按余弦定理自动弯折。
2. **膝盖弯向切换**：拖脚端越过根关节高度后膝盖弯错方向 → 选中 IKC: Elbow → 勾选 `IKC: Bend Flip`。预期：膝盖立刻翻到另一侧，动画全程保持该弯向。
3. **软管肢体可视化**：Create IK 之后点 Create Hose。预期：多出 IKC: Hose 形状层，一条从髋到脚的平滑弯管实时跟随；调 `IKC: Thickness` 加粗成"软肢体"；拖动手掌端软管全程贴合关节。

### 8.5 常见问题

1. **Create Hose 报错？** 需要 AE 15.0+ 的 createPath 表达式（弹窗已注明）；且必须先 Create IK（Hose 从 Elbow 层 comment 里读根/末层名，comment 被手动改过会提示重建）。
2. **拖末端没反应或肢体绷直？** 检查两件事：末端层是否被父化/表达式驱动到了可达域之外（公式会把距离钳到 L1+L2 内=绷直）；L1/L2 是否被误改过小——在 IKC: Elbow 效果控件里改回。
3. **肢体图元方向不对？** 装配约定要求 artwork 旋转 0 时沿 +X、锚点在关节——不满足时旋转表达式会把图元带偏，先摆正素材锚点与朝向再建 IK。

### 8.6 与原版差距（一句话）

没有 RubberHose 的样式库/Rubberize 肢体外观替换、成品化控制面板与弯折柔度风格参数——本体就是"两骨 IK + 贝塞尔软管"的核心骨架（该目录无 README，对照以源码头注为准）。

## 9. EaseAndWizz Clone（easeandwizz-clone）—— 数学缓动预设

### 9.1 它解决什么问题

### 9.3 参数逐个详解（以下基于源码推导）

**预设下拉（26 条，默认选中第 8 项 "Cubic Out"）**：Sine/Quad/Cubic/Quart/Quint/Expo/Circ 七族 × In/Out/InOut 共 21 条 ease 类（写时间缓动手柄）；Back In / Back Out / Elastic Out / Bounce Out / Wizz Out 5 条 sample 类（过冲曲线，逐帧采样插中间键，段内旧中间键先清理，可安全重复应用）。近似表为公开的 Penner→cubic-bezier 标准近似。

**基础倍率（滑杆 20–300 即 0.2–3.0，默认 1.00）**：缩放曲线强度。ease 类：倍率放大手柄偏移；sample 类：放大过冲幅度（内部钳制 [0.2, 3]）。**实际倍率 = 基础 × 连续次数 × 抖动**。

**连续点击自动加倍（勾选框，wizz 特性）**：勾选后 **3 秒内连续点 Apply**，倍率按次数累加（第 1 次 ×1、第 2 次 ×2、第 3 次 ×3……）；间隔超 3 秒或点「重置」回到 ×1。用途：对着预览连点直到过冲幅度满意。

**应用规则**：作用于全部选中属性的相邻选中关键帧段（起键写出方向手柄、末键写入手柄，InOut 双侧都写）；过冲类在段内按合成帧率逐帧插值（上限 300 中间键），插值统一为 LINEAR。

### 9.4 三个演示场景

1. **歌词急停入场**：文字层 position 选中一段两端关键帧 → "Expo Out" → Apply。预期：几乎瞬间到位后缓缓停住（Expo Out 前段极陡）；对比 "Cubic Out" 感受指数与三次方的差别。

3. **批量打破机械感**：全片 30 个元素都选中 → "Cubic Out" + 随机抖动 20% → Apply。预期：各元素强度在 ±20% 内随机，整体统一但不呆板。

1. **过冲类（Bounce/Elastic/Wizz）应用后曲线被 AE"抹平"？** 这是修复前的旧版 bug（插值枚举拼错被静默吞掉），请确认用的是修复后版本；修复后插帧统一 LINEAR，曲线按公式走。

3. **未实机验证，建议先在测试工程试**；自定义循环表达式按**关键帧索引**（K1/K2 字面量）引用段，应用后增删该属性的关键帧会使表达式指向漂移——定稿后再应用循环。

### 11.3 参数逐个详解（以下基于源码推导）

**Zone 1 · Standard loop（side 下拉 loopOut/loopIn + mode 下拉 + Apply）**：写 AE 原生 loop 表达式，mode 四选一：cycle（原样循环）/ pingpong（往复）/ offset（累加循环）/ continue（沿末速度延伸）。作用于选中属性的**全部关键帧**。

**Zone 2 · Custom segment loop（mode 下拉 cycle / "offset (Again! style)" + reps 输入框 0=无限 + Apply）**：**时间线选中的关键帧 = 循环段**（只选一个键时自动取首尾键为段）。cycle 原样重播；**offset 每轮在上一轮终点上叠加段的首尾值差**——同一段"抬手 10px"的动画循环 5 次，手会一路抬 50px。reps=0 无限循环，填 N 播 N 轮后停。

**Zone 3 · Custom pingpong（reps 输入框 + Apply）**：选中键段往复播放，回程可选 smoothstep 缓动（往返两端不生硬）。

**Zone 4 · Time remap loop（按钮）**：对图层启用 timeRemapEnabled 并在 time remap 上写 loopOut——把整段素材/预合成当循环素材用（配合素材层的循环用途）。

**表达式安全**：自定义表达式采样点恒落在段内纯 value 分支，valueAtTime 递归深度 ≤2（源码头 SAFETY NOTE 有专门论证），不会栈溢出。

### 11.4 三个演示场景

1. **走路循环接力前进**：角色位移打一个"迈一步"的段（两键）→ 选中两键 → Zone 2 mode=offset (Again! style)、reps=0 → Apply。预期：角色一步一步往同方向走，每步幅度与源段一致——Again! 的招牌语义。
2. **摆锤往复**：摆锤 rotation 打一个摆动段 → Zone 3 pingpong + 回程缓动 → Apply。预期：摆过去再平滑摆回来，两端无顿挫。
3. **循环素材无缝垫长度**：循环素材层 → Zone 4 Time remap loop。预期：素材自动循环铺满合成时长，不用手动复制时间重映射关键帧。

### 11.5 常见问题

1. **改了段内关键帧后循环乱了？** 自定义表达式按关键帧**索引**（第 K1~K2 个键）引用段——段前增删键会使 K1/K2 指偏。规避：定稿后再应用循环，或重新 Apply 覆盖。
2. **offset 模式循环几轮后数值跑出画面？** offset 是真累加（每轮加值差）——这是 Again! 语义不是 bug；要原样循环用 cycle。
3. **浮动运行面板不见了？** 请确认用的是 review-3 修复后版本（修复前 Window 模式缺 win.show()）；停靠模式不受影响。

### 11.6 与原版差距（一句话）

无自动推断"哪一段该循环"的智能识别与预设记忆，自定义段必须靠选中关键帧指定，timeRemap 只做标准 loopOut。

## 12. Slice it Up Clone（sliceitup-clone）—— 网格切片

### 12.1 它解决什么问题

"照片碎成九宫格飞散开场"、"屏幕分成小块转场"：AE 原生没有无损切分。Slice it Up Clone 对选中图层按 R×C 复制出独立副本、每副本加矩形蒙版裁出对应格子——**蒙版顶点写在源像素空间**，切片与原图层天然原位重合（与 anchor/position/旋转/缩放无关），效果/属性随副本完整保留。

### 12.2 安装步骤详解

公共流程照第 0 节。差异点：

1. 重命名为 `SliceItUpClone.jsx` 放入 ScriptUI Panels 重启 AE；或 Run Script File 运行。

3. **未实机验证，建议先在测试工程试**（review-3 复审通过零修复；网格几何做过 Node 数值验证：gap 间隙精确、外缘贴齐、无缝模式覆盖完整）。文本/形状层的蒙版表现需实机确认（README 已登记）。

### 12.3 参数逐个详解（以下基于源码推导）

**行数 / 列数（输入框，默认 3×3）**：切分网格；R×C 上限 400（防失控），实时显示"将生成 N 块 × 选中图层数"。

**切分对象**：1 个以上可视图层（图片/实拍/预合成/形状均可）；摄像机/灯光自动跳过。切片命名带 `slice_` 前缀（再次对本工具选切片不会连锁误切）。原图层保留不动（切片是副本），每次操作单次 undo 组。

### 12.4 三个演示场景

1. **照片墙碎裂入场**：选中照片层 → 3×3、gap=8、勾随机错位 → Slice。预期：多出 9 个 `slice_*` 副本，各自原位 Hold 后跳到随机错位处；给每片补上飞散关键帧即可。
2. **无缝九宫格转场**：gap=0、不勾随机 → Slice。预期：9 片无缝铺满原图层画面（几何验证过外缘贴齐），分别做缩放/透明度错峰即可成转场。
3. **多图同时切**：选中 4 张图片层 → 2×2、gap=0 → Slice。预期：共生成 16 片（每图 4 片），实时计数先行确认。

### 12.5 常见问题

1. **提示"格子因 gap 过大退化为空"？** gap 大于格子尺寸时该格蒙版退化——减小 gap 或减少行列数。
2. **切片后原画面还在？** 原图层保留是设计行为（无损）——隐藏/删除原图层即可，切片已完整覆盖。

### 12.6 与原版差距（一句话）

没有原版的切片自动延迟动画参数与随机旋转缩放散开预设（本工具只做"Hold→随机偏移"起步），也没有切分形状路径（只做矩形蒙版）。

## 13. Roll It Clone（rollit-clone）—— 真实滚动

### 13.1 它解决什么问题

车轮滚过画面、方块沿路径翻滚：位移与旋转必须按"滚动距离 = 圆周长 × 圈数"联动（角度 = D/(π·直径)·360°），手 K 必然穿帮。Roll It Clone 按图层实际宽度自动算直径，给 Rotation 写联动表达式（位置关键帧随便改、滚动自动跟随）或逐帧烘焙成关键帧，还支持沿蒙版路径的弧长滚动（倒车自动反转滚向）。

### 13.2 安装步骤详解

公共流程照第 0 节。差异点：

1. 重命名为 `RollItClone.jsx` 放入 ScriptUI Panels 重启 AE；或 Run Script File 运行。
2. main.jsx 为**纯 ASCII**（界面英文），对照本节参数使用。
3. **未实机验证，建议先在测试工程试**。review-3 修复了沿路径模式的蒙版 matchName 拼写（`ADBE Mask Group`→`ADBE Mask Atom`，修复前沿路径模式必然报"No mask found"）——本节以修复后代码为准。

### 13.3 参数逐个详解（以下基于源码推导）

**Mode（单选：Expression (live) / Bake keys）**：表达式模式给 Rotation 写联动表达式（之后改位置关键帧滚动自动跟随，推荐）；烘焙模式逐帧采样位移直接写 Rotation 关键帧（线性插值，适合交接/导出模板）。

**Axis（单选：X (ground) / Y (wall) / Along mask path）**：X=贴地滚动（直径取图层宽）、Y=贴墙滚动（直径取高）、沿路径=蒙版轨迹（仅烘焙）。直径按 sourceRectAtTime 自动取，取不到回退图层宽高。

**Direction / Speed**：Forward/Reverse 单选（贴左墙等场景翻转滚向）+ 倍速输入框（默认 1.0）——倍速直接缩放角速度。

**X/Y 模式工作流**：选中 1 个图层，Position 打 ≥2 个关键帧（缓动随意）→ Apply。表达式模式每帧采样位置差分，旋转零点=第一个位置关键帧时刻；烘焙模式只处理选中键时间范围（选中 ≥2 个位置关键帧时只处理选中的那些）。分离维度图层会自动生成 xPosition/yPosition 变体表达式。

**沿路径模式工作流**：选中 2 个图层（**有蒙版的那个是轨迹**，与选择顺序无关）→ Apply。时间窗=工作区（无工作区用滚动层位置键范围）。脚本把滚动层 Position 逐帧摆到蒙版路径等弧长点上并写联动 Rotation；**会清空滚动层现有 Position 关键帧与表达式**（单次 undo 可撤）。弧长用贝塞尔细分+累计表，往返路径按相邻位移点积判向——倒车滚向自动反转。

### 13.4 三个演示场景

1. **车轮贴地滚过**：车轮层 position 打"从左到右"两键 → Expression + X → Apply。预期：rotation 自动按位移/周长联动（位移 314px、宽 100px ≈ 转 1 圈）；之后拖动关键帧改速度，滚动自动跟随。
2. **方块沿 S 曲线翻滚**：建轨迹层画蒙版曲线 → 选中 方块层 + 轨迹层 → Along mask path → 拉好工作区 → Apply。预期：方块沿曲线每帧落位并真实翻滚，路径折返处滚向自动反转。
3. **贴墙下落**：图层沿 Y 轴下移两键 → Expression + Y → Apply。预期：图层贴"右墙"下滚旋转方向正确（贴左墙用 Reverse 翻转）。

### 13.5 常见问题

1. **沿路径报"No mask found"？** 用修复前版本会必现（matchName 拼错）——确认修复后版本；且两个选中层里必须有且只有一层带蒙版。
2. **沿路径模式把我原来的位置动画清了？** 该模式重写滚动层 Position 键（设计行为），单次 Ctrl+Z 撤销；需保留原动画就用 X/Y 表达式模式。
3. **滚动半径不对/穿地？** 直径=图层包围盒宽（X 轴）是近似口径——非圆形图层（矩形滚"棱"）会近似；把图层做成实际滚径一致的图形即可。

### 13.6 与原版差距（一句话）

没有原版的沿任意路径实时表达式模式（路径为烘焙实现）、无摩擦/加减速物理参数与多轴组合滚动。

### 14.1 它解决什么问题

表达式驱动的动画（wiggle、绑定联动）要交给不用表达式的人、导出给模板、或想"定格"某次随机结果：AE 自带的"Convert expression to keyframes"一次只处理一个属性且无选项。Easy Bake Clone 批量烘焙：作用域/时间范围/采样步长可选，静态段自动抽稀，可顺带清旧键、移除表达式。

### 14.2 安装步骤详解

公共流程照第 0 节。差异点：

1. 重命名为 `EasyBakeClone.jsx` 放入 ScriptUI Panels 重启 AE；或 Run Script File 运行。
2. main.jsx 为**纯 ASCII**（界面英文），对照本节参数使用。
3. **未实机验证，建议先在测试工程试**（review-4 复核通过零修复；`parentProperty` 表外 API 已包 try/catch 并 README 登记）。

### 14.3 参数逐个详解（以下基于源码推导）

**Scope（单选：Selected properties / Selected layers (all expr props)）**：只烘时间线选中的表达式属性，或对选中图层递归收集**全部**表达式驱动的属性（深度上限 12；SHAPE/源文本/标记/自定义值类型刻意跳过）。

**Range（单选：Work area / Layer in/out / Whole comp）**：烘焙时间窗。工作区为空会明确报错；图层范围按属性属主层 inPoint/outPoint（回溯失败退化为全合成并给 warning）。

**Step (frames)（输入框默认 1，1–100）**：每 N 帧采一个样。步长越大键越少越粗糙；静态优化开着时大步长也能保形。

**通用**：采样用 valueAtTime(t, preExpression=true)（取表达式前真实值，避免自激励）；写入键统一线性插值，位置类属性关闭 roving；单次 undo 组；每属性采样上限 5000；失败逐条收集 warning（上限 10 条展示）不中断整批。

### 14.4 三个演示场景

1. **定格 wiggle**：抖动层 scale 选 Wiggle 表达式属性 → 范围=工作区、步长 1、清旧键+静态优化开 → Bake。预期：工作区内逐帧键、帧间不变段被抽稀；勾上移除表达式后彻底变成纯关键帧动画。
2. **交接给模板组**：绑定工程里选中全部角色层 → Scope=Selected layers → 范围=图层 in/out → Bake（移除表达式开）。预期：层上所有表达式属性一次性烘焙成键，交出去的工程不依赖表达式环境。
3. **长片瘦身**：长 comp 里多个表达式属性 → 范围=Whole comp、步长 2 → Bake。预期：键量减半仍保形（步长 2 的折线近似在缓曲线上几乎看不出）。

### 14.5 常见问题

1. **烘焙后个别帧值跳变？** 该属性的采样点曾抛异常（表达式引用了不存在的图层等），跳过的帧没键——看状态栏 warning 定位表达式错误。
2. **位置烘焙后轨迹变直线感？** 步长太大或静态优化抽稀过度——步长回 1，或对曲线剧烈段分范围多次烘焙。
3. **出现"Cannot resolve owning layer"警告？** Layer in/out 范围回溯属主层失败，已自动退化为全合成烘焙——介意就改用工作区范围。

无采样步长自适应与进度显示，SHAPE 路径表达式不烘焙，也没有图形化的"只烘选中子段"预览。

### 15.3 参数逐个详解（以下基于源码推导）

**Zone 1 · Time flip（Flip time 按钮）**：把选中关键帧在**它们自己的首尾跨度**内镜像（newTime = t0+t1−t）：值不变、入/出插值互换、缓动速度取反（时间镜像=倒放）。落点撞未选中键的键**原地保留不丢**（review-4 修复：旧版先删后建会丢值）；镜像互换对正常翻转。

## 18. Parrot Clone（parrot-clone）—— 动画接力

### 18.1 它解决什么问题

尾巴、触手、一串弹幕、多节机械臂：后一节重复前一节的运动但**延迟一拍**——手写 valueAtTime 表达式又长又容易错。Parrot Clone 给选中图层按顺序写入接力表达式：驱动层的动画按"每级 N 帧"的延迟逐层复现，可带值偏移，位置/旋转通吃。

公共流程照第 0 节。差异点：

1. 重命名为 `ParrotClone.jsx` 放入 ScriptUI Panels 重启 AE；或 Run Script File 运行。

### 18.3 参数逐个详解（以下基于源码推导）

**应用属性（下拉：Position 位置 / Rotation 旋转）**：接力哪个属性。位置模式写 position 表达式（2D/3D 自适应）；旋转模式写 rotation（2D zRotation）。

**接力次数（输入框默认 0=全部）**：>0 时只给前 N 个接力层写表达式。

**值偏移 X / Y / 角度（输入框默认 0）**：接力值在源值基础上加的静态偏移（位置像素、角度度数）——尾节错位排布用。

**Clear 清除（按钮）**：只清除**本工具写入**的表达式（带 `Parrot Clone (clean-room)` 标记检查，review-4 修复），用户自写表达式不受影响。

**防护**：有父级的接力层在位置模式下跳过（父层坐标系错位）；位置关键帧不被破坏（表达式覆盖显示，键保留）；单次 undo 组。

2. **弹幕接力入场**：10 条字幕层全选 → 固定延迟 5 帧 + 值偏移 Y=40 → Relay。预期：每条字幕比上一条晚 5 帧入场且整体下移 40px 阶梯排布。
3. **旋转接力**：一串齿轮层 → Rotation 模式 + 角度偏移 15 → Relay。预期：每片齿轮复现驱动齿轮的转动并错开 15° 相位。

### 18.5 常见问题

1. **接力顺序不对？** 驱动层是**时间线最上层**的选中层，不是点击顺序——用图层顺序控制接力方向。
2. **位置接力后位置不对？** 该层有父级（父层坐标系错位被防护跳过）——解除父级或改用旋转模式。

### 18.6 与原版差距（一句话）

3. **未实机验证，建议先在测试工程试**（review-4 后新批次实现；弹簧有稳定域钳制，极端参数自动收缩）。

### 21.3 参数逐个详解（以下基于源码推导）

**内边距 px（输入框默认 10）**：果冻盒比图层内容大出的留白（盒尺寸 = 内容包围盒 + 2×padding）。

**增益（输入框默认 60）**：速度→幅度换算比例（约每 1000px/s 对应 60% 的目标拉伸）。**调大**：同样速度抖得更狠；**调小**：几乎不动。

**最大幅度%（输入框默认 25）**：scale 拉伸的硬上限（25 = 盒体最多拉到 125%/压到 75% 附近）——安全带，防止快速运动炸形。

**刚度（输入框默认 120）**：弹簧回正的劲头。**调大**：抖动频率高、恢复快；**调小**：软糯慢弹。极端值受稳定域钳制（自动收缩，表现为突然变"稳"）。

**阻尼（输入框默认 9）**：越大停得越快；0 = 永远晃（不建议）。

**Create 创建 / Remove 移除（按钮）**：Create 给每个选中图层生成 `WB:` 前缀的矩形形状层（父级到目标层，盒参数以 WB: 滑杆挂在盒层上，创建后可逐层改）；同层已有果冻盒会跳过。Remove 删除全部果冻盒，目标图层不受影响。单次 undo 组。

### 21.4 三个演示场景

1. **UI 卡片果冻落位**：卡片层 position 打"落下停稳"关键帧 → Create（默认参数）→ 播放。预期：卡片到位瞬间果冻盒沿运动方向拉伸再弹回方正；速度越快形变越大。
2. **标题挤压回弹**：标题层快速甩入 → Create + 增益 120、最大幅度 40 → 播放。预期：入场瞬间明显压扁拉长然后弹回（参数挂 WB: 滑杆可边播边调）。
3. **给静态照片加"活"感**：照片层做轻微往复位移动画 → Create + 增益 30。预期：照片外围果冻盒随微动轻轻呼吸，低调不抢戏。

### 21.5 常见问题

1. **果冻盒不动？** 目标层 position 相邻帧位移为零（速度驱动的弹簧没有输入）——给目标层加位移动画，或调大增益。
2. **盒子形状炸了？** 速度极大触顶 Max Amp 或稳定域钳制生效——调小增益/加大阻尼，或提高 Max Amp 上限前先确认真的需要。
3. **想要别的盒子形状？** 盒层是普通矩形形状层——直接改它的圆角/描边/填充，弹簧在 scale 上不受影响。

### 21.6 与原版差距（一句话）

只有矩形盒一种外观（无原版形状替换/自定义锚点模式），弹簧只吃 position 速度（不吃旋转）。

## 22. Limber 2 Clone（limber2-clone）—— 双骨 IK 肢体

### 22.1 它解决什么问题

角色走路/站立时，手脚得钉在原地，身体怎么动都不该撕开。手 K 做不到，得让 AE 帮你解三角。这个复刻建「1 个渲染层 + 2 个控制器」，拖控制器让肢体自动弯折伸直（IK），也可混到 FK 或自由关节（FreeK），并用「生成手/生成脚」把末端接上现成素材。原版 $65。

### 22.2 安装步骤详解

同 §0。**必须先激活一个合成**（脚本头部会提示），否则直接报错。62,641B / 1322 行，界面中文（UTF-8 带 BOM）。

### 22.3 参数逐个详解（面板分六组）

| 控件 | 作用 |
|---|---|
| **选择组**：`交换根/末` | 若你选中两层的顺序反了，勾这个不用重选 |
| `创建时打首帧` | 建好后立刻在当前帧记录初始姿势，避免第一帧空 |
| `反向弯` | 弯向取反（等价原版 Clockwise 的 ±100%） |
| **长度组**：`自动（0.58×当前间距）/ 手动` | 自动按两层间距估骨长；手动可在下方填上/下段长度 |
| **样式组**：样式预设下拉 + `应用样式` / `存为预设` | 描边粗细、颜色、端点等成套切换；自调好一套可存下来 |
| **手/脚组**：`生成手` `生成脚` `绑定到末端` `手/脚跟随肢体旋转` | 生成末端素材层并 parent 到终点控制器；勾「跟随旋转」让它随肢体转向 |
| **关键帧组**：`当前姿势打帧`、`连根一起`、`生成 4 姿势循环` | 打当前姿态；`生成 4 姿势循环`一次铺一个走循环骨架 |
| 主按钮：`创建肢体` / `移除` / `移除全部` | 建 / 删当前选中肢体 / 清空本合成所有肢体 |

### 22.4 三个演示场景

1. **简单的走路腿**：建两条腿 → 分别把起点控制器 parent 到身体层 → 拖终点控制器到落地点 → `生成 4 姿势循环` → 整体按 BPM 调帧距。
2. **手举手**：建一条手臂 → `生成手` → 勾「手/脚跟随肢体旋转」→ 拖手的位置，肘自动找弯。
3. **客户要求"胳膊再长一点"**：选肢体，改长度组的数值即可（重打一次样式不会丢控制器）。

### 22.5 常见问题

- **拖出 NaN / 肢体消失**：控制器两点重合或拉得远超骨长总和时最容易。本复刻对这两处退化区加了 epsilon 保护，但**仍建议避免两点完全重合**；真出现了删掉重建即可。
- **肢体不动、控制器却乱飞**：多半是渲染层的表达式被关掉了（属性右键「移除表达式」）。重跑一次 `创建肢体` 或把表达式恢复。
- **控制器在画面里看不见**：控制器是引导层（guide layer），**它本来就不出画面**，只用于拖动。
- **两段之间有明显折角**：这是 Path 型的正常表现（原版靠 Curvature 变弯），本复刻不提供 Curvature 旋钮。

### 22.6 与原版差距（一句话）

只做 **Path 型 + 2 骨 + IK/FK 混合**这条主线；原版的 3 骨、Precomp/木偶型肢体、Indicators、Limb Library、Matching、Auto-flop 均未实现，且用 Slider 控件代替原版的伪效果面板。

## 23. Overlord Clone（overlord-clone）—— Ai/SVG → AE 单向形状传输

### 23.1 它解决什么问题

Illustrator 里画好的元素，正常流程要「存盘 → 导入 → 手动重新分层/上色」，几十个形状能磨一小时。这个复刻直接把 **SVG 变成 AE 形状层**：分组、命名、填充、描边尽量照搬，改完还能用「更新」原地覆盖。原版 $75（它是双向的，这里只做 Ai→Ae 单向）。

### 23.2 安装步骤详解

同 §0。**不需要装 Illustrator 端扩展**（原版双向才需要）。36,984B / 962 行，界面英文。

用法两条路：①Ai 里 `File > Save a Copy` 存成 `.svg`，面板 `Browse...` 选文件；②Ai 里选中 `Edit > Copy`，把内容粘贴到面板的多行文本框。

### 23.3 参数逐个详解

| 控件 | 作用 |
|---|---|
| 文件路径框 + `Browse...` | 选一个 .svg 文件 |
| 多行文本框 | 直接粘 SVG 源码（免存盘） |
| `Update with keyframe at current time` | 更新时在当前时间打关键帧，而不是覆盖唯一形状 |
| `Build shape layer` | 新建一个形状层 |
| `Update selected layer` | 用同一份 SVG 覆盖**当前选中层**的形状（靠图层注释里的来源标记找回） |

### 23.4 三个演示场景

1. **PV 分镜元素**：Ai 画好一组图形 → 存 SVG → 建层 → 在 AE 里直接加 Trim Paths / 位移做动效，不用重新描。
2. **客户改了个颜色**：Ai 里改完再存一次 → 选中原层 → `Update selected layer` → 颜色/形状原地更新，效果器一个不少。
3. **图标做分镜格子**：一次导入多个 `<g>`，一个 group 一层，用 Rows and Columns（第 17 件）排格子。

### 23.5 常见问题

- **弧线（SVG 的 `A` 命令）变成直线**：未实现弧转贝塞尔，会被降级成直线并告警。解法：Ai 导出时选「SVG 1.1 + 保持路径精度」，或先用 AE 的形状工具修。
- **渐变变成纯色**：只支持两站纯色近似；多站/径向不还原。
- **文字没导进来**：SVG 里的 `<text>` 不处理（字体度量拿不到）。先在 Ai 里 `Create Outlines` 再导出。
- **图层名变成 `Group 1`**：SVG 里没有 id/label 时只能编号；在 Ai 里给图层命名即可。

### 23.6 与原版差距（一句话）

只做单向、只走 SVG 中转；双向传输、Ai 文本层、完整渐变、Photoshop/Figma 通道、参数化形状识别都靠边（`rect`/`ellipse` 会尽量建成参数化形状，这是与原版对齐的一点）。

## 24. Keyframe Parent Clone（keyframe-parent-clone）—— 关键帧组「父化 / 平移 / 拉伸」

### 24.1 它解决什么问题

AE 没有「关键帧组」。想把一整段动画整体提前 3 帧、或者整体拉慢 20%，标准做法是逐个属性拖。这个复刻把你选中的一批关键帧捕获成一个组，然后**整体平移、整体缩放时间/数值**，还支持「保持比例」和「缓动同步缩放」。原版 $24.99。

### 24.2 安装步骤详解

同 §0。36,077B / 933 行，界面英文，五区面板。

### 24.3 参数逐个详解

| 区 | 控件 | 作用 |
|---|---|---|
| 1 Scope | `Capture selection` | 捕获当前时间线里所有选中的关键帧（可跨图层、跨属性）；抓不到会报错而不是静默 |
| 2 Parent | 父键下拉 `(auto) earliest key…` / `组名 @ 时间` | 指定支点键；默认各属性最早键 |
| | `Set parent` / `Clear` | 设定 / 取消父键 |
| | `Move group so parent sits at [0.00]s` | 把父键精确挪到某秒，子键整体跟随 |
| 3 Translate | `Δt`（±5 s，0.001 s 精度）/ `Δv`（X/Y/Z，±500） | 整体时间/数值平移；负值即前移 |
| 4 Stretch | `sT` 10%–400% / `sV` 10%–400% | 时间缩放 / 数值缩放（以父键为支点） |
| | `keep ratio` | 勾上后 `sV = sT`，拉长时间同时等比放大数值 |
| | `rescale ease speeds`（默认开） | 缓动速度随缩放同步换算，拉伸后曲线形状不走样 |
| 5 | `Preview` / `Apply` / `Restore` / `live preview` | 预览 / 写入 / 回原始布局 / 松手即写入 |

范围上限：属性树深度 5、单次最多 40 个属性——超了会提示分批做。

### 24.4 三个演示场景

1. **整段动画提前 3 帧**：捕获 → 父键选段首 → `Δt = -0.125`（24fps 下 3 帧）→ Apply。
2. **客户说"这段慢一点"**：`sT = 150%`，保持 `rescale ease speeds` 开着，曲线手感不变、只是拉长。
3. **整段数值放大 2 倍（缩放动画）**：`sV = 200%`，不勾 `keep ratio`（否则时间也被拉长）。

### 24.5 常见问题

- **Apply 后键变少了**：目标时刻被组外的键占用时会冲突，脚本会报「键会塌陷」并计数，不会静默丢——按提示先删掉冲突键。
- **预览正常、Apply 后跳变**：多半是同一属性上有表达式在覆盖，先把表达式临时关掉。
- **数值框不动**：勾掉了 `live preview`，需要按 `Preview` 才刷新数值。

### 24.6 与原版差距（一句话）

只做「选中键组 → 参数化变换 → 写入」这一条链路；原版未公开的交互（时间线内拖拽手柄、吸附、曲线可视化、预设库）不实现也不声称。

## 25. Easify 4 Clone（easify4-clone）—— 缓动面板（批量 / 同步 / 循环）

### 25.1 它解决什么问题

手动改速度图有两个痛点：一是**一批关键帧要点很多次**，二是**换了属性缓动就得重调一遍**。这个复刻把缓动做成预设表一键套，还能把 A 属性的缓动套到 B 属性（时间按比例自动映射），并补了循环与整体位移。原版 $49，**原版还有 Premiere Pro 端，这里没有**。

### 25.2 安装步骤详解

同 §0。28,060B / 745 行，界面英文。顶部有一行 `Selection:` 探针，实时显示当前选中了几个属性/关键帧——**先看它确认选中对了再点按钮**。

### 25.3 参数逐个详解

| 控件 | 作用 |
|---|---|
| 预设下拉 + `Apply preset` | 套用缓动预设（只改 ease，不改值与时间） |
| `Only selected keys (else every key)` | 默认只作用于选中键；不勾则整个属性所有键一起改 |
| `Flat handles (speed = 0, classic AE)` | 出「经典 AE 缓入缓出」手感（速度归零、只留影响量） |
| 同步区：`Set source` → `Apply to others` | 第一个选中的属性当源；套到其余选中属性，**时间按目标段长归一化缩放** |
| 循环区：`Ping-pong` / `Repeat (offset)` + `times` + `Loop` | 乒乓往返 / 原样重复并位移 |
| `Shift by frames` + `Shift` | 选中键整体时间位移（帧） |
| `Distribute keys evenly` | 选中键在首末之间等距重排 |

### 25.4 三个演示场景

1. **一条时间线统一手感**：框选多个图层的位移动画 → 勾 `Only selected keys` → 套「缓入缓出」→ 一次全部生效。
2. **复用一个手感**：在已经调好的属性上 `Set source` → 选其它属性 → `Apply to others`，1 秒的缓动到 0.5 秒段上会自动压缩。

### 25.5 常见问题

- **点了没反应**：`Selection:` 是 `-`，说明没有真正选中属性（只选了图层不算）。
- **缓动套上后运动幅度变了**：说明该属性原本是 HOLD/LINEAR 键。本复刻会先转 BEZIER 再改，若仍异常，先手动把键改成「贝塞尔」再套。
- **多维属性（缩放/位置）报错**：早期版本对维度匹配敏感，现已按维度补齐；若遇到，用 `Only selected keys` 逐维度处理。

### 25.6 与原版差距（一句话）

只有 AE 端（原版还有 PR 面板）；多点曲线/弹性曲线用「采样近似」实现而非真正的多控制点曲线；路径缓动、复合曲线、进/出转场未实现。

## 26. Retend Clone（retend-clone）—— 整棵嵌套树重定时 / 延长

### 26.1 它解决什么问题

客户把 30 秒改成 45 秒，你的主合成里嵌着 6 层预合成——逐个进去改时长、拖关键帧能干一下午。这个复刻对**整棵 precomp 树**统一处理：要么只延长时长（动画不动），要么整树重定时（关键帧/标记/工作区一起按比例缩）。原版 $29。

### 26.2 安装步骤详解

同 §0。38,798B / 885 行，界面中文。先选中一个 precomp 图层（或取消选择作用于当前合成），点 `刷新选中` 让面板认出目标。

### 26.3 参数逐个详解

| 控件 | 作用 |
|---|---|
| `刷新选中` | 重扫当前目标并显示根信息 |
| 模式（二选一） | **延长**：关键帧不动，动画结束后由 AE 原生 hold 语义停在最后一帧；原贴合旧 comp 结尾的图层出点随之延长<br>**重定时**：comp 时长、图层入出点、关键帧时间、已有时间重映射（键时间与键值）、标记、工作区全部同步缩放 |
| `目标时长（秒）` | 期望的最终时长，脚本反算比例 |
| `延长原贴合 comp 结尾的图层出点` | 只对延长模式有效 |
| `素材层同步变速` | 只对重定时模式有效：给素材层写入时间重映射 |
| 影响范围 | 显示整棵嵌套 precomp 树（含根），执行前确认层级对 |
| `执行` / `取消` | 整个操作一个撤销组 |

### 26.4 三个演示场景

1. **客户要求从 30 秒变 45 秒**：延长模式 → 目标 45 → 执行。画面节奏完全不变，只是结尾多 15 秒静止（用在片尾留白很合适）。
2. **整片统一慢 20%**：重定时模式 → 目标 = 原时长 × 1.2 → 执行。关键帧、标记、工作区一起变。
3. **素材也要跟着变速**：重定时 + 勾 `素材层同步变速`，素材层会带时间重映射。

### 26.5 常见问题

- **执行后某些层没变**：表达式里写死了时间（如 `valueAtTime(2,…)`）不会被缩放，这是原理限制，README 有警告。
- **音频变调**：重定时会缩放音频层，音调会变。需要保音调的活儿，把音频层排除或后期在 Audition 处理。
- **同一棵树被执行两次**：脚本按对象同一性防重，重复执行不会二次缩放；但换模式重跑前建议先撤销。
- **目标时长填错**：`取消` 一步退出，或 Ctrl+Z 整组回退（一个撤销组）。

### 26.6 与原版差距（一句话）

做「整体比例」这一档，不做非线性变速（曲线重定时）；原版的分辨率缩放未实现（只处理时间维度）。

## 27. Scribe Clone（scribe-clone）—— 单线字型书写动画

### 27.1 它解决什么问题

"字一笔一笔写出来"这个效果，正常做法是给每个字母做遮罩或 Trim Paths 再逐字排期，一条标题能干半小时。这个复刻内置**单线字形数据**，输入文字一键生成逐字书写的描边动画。原版 $30。

> **版权提醒**：原版价值的一半在 6 套单线字型资产，那是版权物、不复刻。本复刻用的是**公有领域 Hershey 单线字体**（1970 年代起进入公有领域），行为等价、字形不同，**只覆盖拉丁字符**。

### 27.2 安装步骤详解

同 §0。43,461B / 556 行，界面英文。字形数据内嵌在脚本里，**不需要任何外部文件**。

### 27.3 参数逐个详解

| 控件 | 默认 | 作用 |
|---|---|---|
| `Typeface` | — | 单线字形套（几套不同笔感） |
| 文本框 | `Hello 2026` | 要写的文字；支持换行 |
| `Font size` | 100 | 字号（px） |
| `Tracking %` | 15 | 字距百分比 |
| `Line height %` | 120 | 行高（多行时生效） |
| `Stroke` | 6 | 描边粗细（px） |
| `Colour (hex)` | FFFFFF | 颜色，六位十六进制，不带 `#` |
| `Delay per glyph (frames)` | 2 | 每个字母比上一个晚几帧开始写 |
| `Stroke time per glyph` | 6 | 每个字母写多久（帧） |
| `Write text` / `Reset defaults` | — | 生成 / 恢复默认值 |
| 状态栏 | `Ready.` | 报告生成了几个字母、总时长 |

总时长 ≈ `字母数 × (Delay + StrokeTime)` 帧。

### 27.4 三个演示场景

1. **歌词标题**：输入一行 → `Delay 3 / Stroke 8` → 生成后整体放到时间线开头。
2. **签名感片尾**：`Stroke 12`、`Colour FFFFFF`、单行短句，结尾保持到片尾。
3. **配卡点**：把 `Delay` 调到与 BPM 对齐（如 24fps 下 120BPM = 12 帧/拍，Delay 取 6 得半拍一个字）。

### 27.5 常见问题

- **中文变空白**：字形库只有拉丁字符。中文请用「文字层 → Create Shapes from Text」再做 Trim Paths（效果是轮廓显现，不是单线书写）。
- **字母糊在一起**：`Tracking %` 调大（15 → 25）。
- **生成后是一堆散层很难管**：脚本给每个字母一层，建议建个空对象 parent 起来整体移动。
- **颜色填了 `#FFFFFF` 报错**：去掉 `#`，只写六位。

### 27.6 与原版差距（一句话）

机制等价（文字 → 单线路径 → Trim Paths 顺序写入），但没有原版的 6 套字型资产、没有中文、没有笔锋变化。

## 28. Move Anchor Point Clone（move-anchor-point-clone）—— 锚点移动不动画面

### 28.1 它解决什么问题

改锚点是「缩放/旋转中心」的事，但直接拖锚点画面会跑。正确做法是锚点与 position 联动补偿——手工算很烦，尤其一次改多层。这个复刻给一组九宫格按钮，点哪儿锚点就挪到哪儿，画面纹丝不动。原版 $29.99（v4 已是 aex 原生插件，这里是 jsx 逻辑版）。

### 28.2 安装步骤详解

同 §0。11,632B / 316 行，界面英文。**先选中要处理的图层**（可多选）。

### 28.3 参数逐个详解

| 控件 | 作用 |
|---|---|
| 九宫格按钮（`0,0` / `0.5,0` / … `1,1`） | 把锚点移到该相对位置；`0,0` 左上、`0.5,0.5` 居中、`1,1` 右下 |
| `X:` / `Y:` 输入框（默认 0.5 / 0.5） | 任意比例位置，`Apply` 生效 |
| 状态栏 | 报告影响层数与失败数 |

### 28.4 三个演示场景

1. **要做呼吸缩放**：选中图层点 `0.5,0.5`，锚点到中心，缩放不再偏心。
2. **门的旋转**：点 `0,0.5` 把锚点放到左边中部，旋转就像合页。
3. **批量整理角色层**：全选点 `0.5,1`（底部居中），后续所有层的对称变换都稳。

### 28.5 常见问题

- **画面跑了**：说明该层 position 带了关键帧且表达式在覆盖——先关表达式或先删关键帧再改。
- **只动了一层**：多选时如有层被锁定/隐藏，脚本会跳过并计数。
- **旋转/缩放值没变**：本工具只改锚点与 position，不动 scale/rotation。

### 28.6 与原版差距（一句话）

锚点与 position 的补偿逻辑等价，功能不缺；差别在交互手感与大数量时的速度（原版是编译插件）。

## 29. Trim Comp Clone（trim-comp-clone）—— 合成时长裁到内容

### 29.1 它解决什么问题

从模板/别人的工程接手，comp 时长常常是 30 秒但内容只有 6 秒，导出时白渲染、时间线也难看。这个复刻把 comp 时长精确裁到「内容的首尾」或按需要延长。原版 $4.99（NYOP）。

### 29.2 安装步骤详解

同 §0。11,935B / 320 行，界面英文。打开后点 `Refresh` 让它读当前 comp。

### 29.3 参数逐个详解

| 控件 | 作用 |
|---|---|
| 头部 `Comp:` / `Contents:` / `Duration:` / `Target:` | 当前合成名 / 内容首尾 / 现时长 / 裁完的目标时长——**先看这行再点** |
| `Ignore guide layers` | 忽略引导层（控制器之类不算内容） |
| `Ignore disabled layers` | 忽略关掉的图层 |
| `Follow nested precomp length` | 按嵌套预合成的实际长度算（而不是它在外面的可见段） |
| `Slide contents to start at 0` | 内容整体左移到 0 秒开始 |
| `Only selected layers (if any selected)` | 有选中层时只按选中层算 |
| `Tail padding (frames)` | 尾部留几帧余量 |
| `Refresh` / `Trim to Contents` | 重读 / 执行（一个撤销组） |

### 29.4 三个演示场景

1. **接手模板瘦身**：打开 comp → 勾 `Ignore guide layers` → `Refresh` → `Trim to Contents`，30 秒变实际长度。
2. **结尾留 12 帧气口**：`Tail padding = 12` 再裁。
3. **内容不在 0 秒开始**：勾 `Slide contents to start at 0`，一次挪齐。

### 29.5 常见问题

- **裁短了，动画被切**：内容判定只看层的入出点，若你的动画靠表达式/时间重映射延长，勾 `Follow nested precomp length` 或手动加 `Tail padding`。
- **裁完时长为 0**：所有层都被忽略（全 guide 或全 disabled），先看头部 `Contents:` 是否为 `-`。
- **嵌套 comp 没跟着变**：本工具只改当前 comp，子 comp 请逐个处理或用 Retend（第 26 件）。

### 29.6 与原版差距（一句话）

行为对齐（裁剪/延长到内容），只少一些未公开的交互细节（原版未公开 UI 细节，本复刻按公开功能描述建立）。
