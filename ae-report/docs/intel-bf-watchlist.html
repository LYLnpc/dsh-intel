一、值得入手（12 件，分三档）

★ 数 = 我建议的购买优先级，不是产品好坏。★★★ 档也允许你一件不买，理由见每条对比栏。

★★★ 真值得（4 件）

1. RubberHose 3 — $65 → 黑五约 $48.75

  • 链接：https://battleaxe.co/rubberhose （Battle Axe 官方；aescripts 亦有分销）
  • 价格：[情报摘要级] $65
  • NYOP：否
  • 为什么值得：手书里"手臂/腿/尾巴"的软肢体，拖两个控制器就弯，是角色动态里最省命的一环。原版比 clone 多的是 Rig 可发布到 Essential Graphics 面板（跨项目复用同一套绑定）、Buttcapper 端点工具、样式库。
  • 免费替代对比：本机 rubberhose-clone（两骨 IK 解算的 jsx 版，能弯、能手脚，核心不缺）；Duik Ángela（GPL 免费，但工作流是"先建骨架再绑"，比它重一档）。

结论：clone 已经覆盖 80% 日常。只有当"角色动态"是你每周都接的活，才值得为剩下 20%（EG 发布 + 赶工手感）掏 $48.75。

  • 与 #12 Limber 2 二选一，别都买。

2. Joysticks 'n Sliders — $39.95 → 黑五约 $29.96

  • 链接：https://aescripts.com/joysticks-n-sliders/
  • 价格：[已核-全文] $39.95 / 格式 jsx / 作者 Mike Overbeck / 兼容 CC–AE 2026
  • NYOP：否
  • 为什么值得：口型、眼神、表情——手书人物的"活起来"就靠这个。一个 2D 摇杆驱动四象限双线性插值，滑杆可无上限叠加姿势。
  • 免费替代对比：本机 joysticks-clone（姿势层 + 插值骨架，Mechanics 等价）。原版多出的是 Path Shape Rigging（把形状路径顶点绑到滑杆，做嘴型/眉形实时变形）、lottie/BodyMovin' 导出兼容、控制器跨 comp 迁移。

结论：如果你要的是"摆姿势"→ clone 够。如果你要"嘴型变形"→ 原版的路径绑定 clone 里没有，值 $30。

3. Overlord — $75 → 黑五约 $56.25

  • 链接：https://battleaxe.co/overlord
  • 价格：[情报摘要级] $75 永久许可
  • NYOP：否
  • 为什么值得：Ai ↔ AE 双向免导入。这是管线级工具，省的不是单次操作而是整条"图形进 AE"的流程。
  • 免费替代对比：本机 overlord-clone 只做单向 SVG→AE；Ai 自带 SVG 导出也能进 AE 但丢文本/渐变编辑性。原版多出的是 反向（AE 形状回写 Ai）+ 实时联动。

结论：先回答一个问题——你的曲绘/图形是在 Illustrator 里画的吗？是 → 双向值这个价；在 PS 里画（手书主流的 PSD 分层流程）→ Overlord 用不上，一分钱别花。

4. Plexus 3 — 约 $59.99 → 黑五约 $45

  • 链接：https://aescripts.com/plexus/
  • 价格：[情报摘要级] ~$59.99 —— 这条我核不动，Rowbyte 官网商品页也在盾后面，实际价可能更高，请以购物车为准
  • NYOP：否
  • 为什么值得：点/线/面程序化网络，PV 里"连接线 / 数据流 / 空间网格 / 粒子星座"是标准视觉语言，本机没有任何等价物（Trapcode Particular 是粒子，不负责按距离连线）。
  • 免费替代对比：无平替。Blender 几何节点能做真 3D 连线但要跨软件；CC Particle World 只能出粒子；本机 31 件复刻件里没有一件涉及点线网络。

结论：清单里唯一"真的没有免费替代"的一件。但它是 C 类原生渲染件 → 只买你确实要做的题材。

★★ 有条件买（4 件）

5. Retend — $29 → 黑五约 $21.75

  • 链接：https://aescripts.com/retend/
  • 价格：[情报摘要级] $29
  • NYOP：否
  • 为什么值得：一键重定时/延长整棵嵌套 precomp 树（子 comp 时长 + 关键帧缩放一起改）。客户临时说"这段拉长 2 秒""整片变速到 25fps"的时候，这是接单里最高频的返工。单价最低、命中率最高的一件。
  • 免费替代对比：本机 retend-clone（递归改子 comp 时长 + 关键帧缩放）；另有免费的 Comp Setting Tool v2.1 管帧率批量改。

结论：clone 够用就不买。但 $21.75 买"改稿不翻车"，性价比全单第一。

6. AutoFill v2 — 约 $74.95–100 → 黑五约 $56–75

  • 免费替代对比：无真正等价（feasible-assessment 明确记"无免费等价，社区普遍认为 ~$100 偏贵"）；只能蒙版 + 关键帧手工近似。

结论：唯一"无平替 + 高频场景"双中，但也是全单最贵、最该先用试用版验证的一件。

7. Rows and Columns — 约 $25 → 黑五约 $18.75

9. Scribe — $30 → 黑五约 $22.50

  • 免费替代对比：本机 rollit-clone（可选档）；手写接触点表达式免费。

12. Limber 2 — $65 → 黑五约 $48.75

  • 为什么值得：可分离关节的 IK 肢体 + 手脚钉地，走路循环比 RubberHose 好控。
  • 免费替代对比：本机 limber2-clone（必装档）；Duik 免费。

二、不值得买（5 件，防冲动）

1. Deep Glow 2 — $99.95

本机已装 Deep Glow（MediaCore 22 项收费件之一）。就算没装，原生多级 Glow + 曲线 + 通道分离能到 80%，Creation Effects 的 Afterglow 预设免费。已拥有 + 有近似 = 双重不值。

2. Optical Flares — $124.95

本机 Sapphire 自带 S_LensFlare（你已装全家），AE 内置 Lens Flare + CC Light Rays 能顶，Creation Lens Flares 是 $0 模板。为"实时可编辑光斑编辑器"这一个交互掏 $125 不值。

3. Element 3D — $149.95

Cinema 4D Lite 随 AE 免费附带，Blender 免费且带 alpha 回 AE。本机已有 C4D Lite 路线，且你是 2D 手书/PV 为主，一年用不到几次实时 3D。

4. Ease Stash — $35（特价 $26.99）

与已装的 Flow + EaseCopy 功能重叠（存曲线/存缓动两件都能干），且有 easestash-clone。缓动类你已饱和，这类是纯粹的重复消费。

5. Datamosh — 约 $25

ffmpeg 去关键帧流程可免费做出真 datamosh（不是伪装），Turbulent Displace 可做"假"的。为省两条命令行花 $25 不值。

另附冷冻名单（不必买，但也不坑）：Hawaiki Keyer 5（内置 Keylight + Key Cleaner + Advanced Spill Suppressor 三件套已够）、Lockdown（手书用不到）、ShapeShifter AE（C4D Lite/Blender）、Move Anchor Point 4（$29.99 买的是 aex 手感，jsx 逻辑等价，clone 已覆盖）、LongShadow 2（复制层偏移即可）、Squirrel（$35 买一个层级树视图，偏贵）、Add Sauce（$9.99，与工具箱类重叠）。

  1. 别在 11/16 13:00 一开卖就清购物车。 25% 是按常规价算；已经在"特价"位的件（paid-list 记：Keyframe Parent $14.99、KeyMaster $18.99、Ease Stash $26.99）能不能叠加没说清。预算一律按常规价 × 0.75 算，别拿特价再乘一次。

五、一个提醒（不是劝你买）

clone 是自研件，经过静态验收（API 白名单 / 语法检查 / 离线断言），但没有作者支持、没有跨版本维护承诺、没有实机批量长跑验证。客户单工期紧的时候，"原版不会在交付前一晚崩"本身就是钱的一部分。这不是要你把 12 件都买了——是说：clone 出问题的那一件，就是该花钱买原版的那一件。 平时不用买，崩过一次就值。
